# Arena SDK Implementation Plan (Plan 2 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@arena/sdk`, the TypeScript library the player daemon (Plan 3) and host server (Plan 4) use for the whole off-chain protocol and all hub interaction. It covers the packed chess encoding, a chess.js-backed mirror of `ChessRules.successor`, EIP-712 State/Close hashing and signing, ABI codecs, a channel-session state machine, and a hub client. All of it is proven to agree with the deployed contracts on a local Anvil chain.

**Architecture:** Pure modules (`encoding`, `chess`, `eip712`, `abiCodec`) form the protocol core and have no I/O. `ChannelSession` is the per-channel state machine. It validates every incoming message exactly as the hub would, signs only through an equivocation guard, and persists through a `SessionStore` before it hands out any signature. `HubClient` wraps `ChannelHub` calls through a pluggable `TxSender`, which is a local key in v1 and Circle CLI later. Parity tests run the TypeScript logic side by side with the Solidity contracts on Anvil.

**Tech Stack:** TypeScript (ESM, run directly with tsx/vitest, no build step), viem 2.56.8, chess.js 1.4.0, vitest 5.0.1, typescript 6.0.3 (typecheck only), Foundry/Anvil for integration tests, pnpm 12.6.0 workspace.

**Spec:** `docs/superpowers/specs/2026-09-24-agent-chess-arena-design.md`. Read §3.1 (TxSender), §4.1–4.6 (contract semantics the SDK mirrors), §6.3 (watchtower needs), §7 (error handling), §8 items 5–7, and §12 (implementation refinements: Close intent, ECDSA-first, NEW_GAME prev needs both signatures). Also read `contracts/README.md`, which is the authoritative encoding reference.

## Global Constraints

- JS deps pinned exactly: `chess.js@1.4.0`, `viem@2.56.8`, `vitest@5.0.1`, `typescript@6.0.3`, `@types/node@25.9.8`, `tsx@4.23.15`. Never bypass pnpm's minimum-release-age gate (no `minimumReleaseAgeExclude`).
- ESM only (`"type": "module"`), NodeNext resolution, relative imports end in `.js`. The package entry is `./src/index.ts`; there is no build step.
- Encodings must equal the Solidity ones exactly (contracts/README.md):
  - square `rank * 8 + file`
  - 4 bits per square; pieces `P N B R Q K = 1..6`, black adds 8
  - meta: side bits 0–7, castling 8–15 (`K=1 Q=2 k=4 q=8`), ep 16–23 (255 none), halfmove 24–39, ply 40–55, status 56–63
  - move `uint32`: from 0–5, to 6–11, promo 12–14 (0 or 2–5), kind 15–18 (`NONE NORMAL NORMAL_OFFER_DRAW RESIGN ACCEPT_DRAW CLAIM_STALEMATE NEW_GAME = 0..6`)
  - status `PLAYING DRAW_OFFERED WHITE_WON BLACK_WON DRAW = 0..4`
- Initial board `0xcabedbac99999999000000000000000000000000000000001111111142365324n`; initial meta `0xff0f00n`; `MAX_PLY = 300`; fifty-move rule at `halfmove >= 100`.
- EIP-712 domain `{ name: "AgentArena", version: "1", chainId, verifyingContract: hub }`.
  - Type `State(bytes32 channelId,uint64 turnNum,bytes32 prevHash,uint256 balanceA,uint256 balanceB,uint32 gameIndex,uint32 move,uint256 board,uint256 meta)`.
  - Type `Close(bytes32 channelId,bytes32 stateHash)`, where `stateHash` is the full EIP-712 digest of the state.
  - `prevHash` is the full EIP-712 digest of the previous state.
- `channelId = keccak256(abi.encode(chainId, hub, params))`.
- viem numeric conventions: `uint64` and `uint256` fields are `bigint`; `uint32`/`uint8` fields are `number`.
- Protocol rules the session must enforce (spec §12, ledger carry-forward):
  - (a) Sign Close only for the latest state, only between games, and only if nothing later has been signed. After signing Close, sign nothing else.
  - (b) Never accept a move on top of a NEW_GAME checkpoint unless it carries both signatures.
  - (c) Never sign two states with the same `turnNum`.
  - (d) Persist before returning any signature.
- Integration tests use Anvil on port **8546** (not 8545), started by vitest global setup. Vitest runs files sequentially (`fileParallelism: false`).
- Every commit message ends with a `Co-Authored-By:` trailer naming the model that wrote it.

## Review Focus

1. **TS/Solidity divergence on a move class.** chess.js accepts a `promotion` on a non-promotion move, while the contract rejects it. Offer-draw flags, a mate on the move that reaches the 50-move or ply limit, and non-canonical encodings must also match. Covered by the Task 4 parity sweep plus curated cases, and by `rejects a promotion suffix on a non-promotion move` in Task 2.
2. **Session accepts what the chain would reject**: a wrong signer, a wrong `prevHash`, a skipped turn, a move on a single-signed checkpoint, or a move out of turn. Covered by the Task 5 session tests.
3. **Double signing after a crash.** A session restored from a stale snapshot must refuse to sign the same turn again. Covered by `never signs twice for the same turn after restoring a stale snapshot` in Task 5.
4. **Rollback through Close**: signing Close with a newer state already signed, or on a state that is not between games. Covered by the Task 5 close tests.
5. **Hub reverts that surface as unreadable RPC errors.** The caller must get the custom error name (e.g. `BadSignature`). Covered by `surfaces hub custom errors by name` in Task 6.

```ts
import { spawn, spawnSync } from "node:child_process";
import { homedir } from "node:os";
import { resolve } from "node:path";

export const ANVIL_PORT = 8546;

async function waitForRpc(url: string): Promise<void> {
  for (let i = 0; i < 100; i++) {
    try {
      const res = await fetch(url, {
        method: "POST",
        headers: { "content-type": "application/json" },
        body: JSON.stringify({ jsonrpc: "2.0", id: 1, method: "eth_chainId", params: [] }),
      });
      if (res.ok) return;
    } catch {
      // not up yet
    }
    await new Promise((r) => setTimeout(r, 100));
  }
  throw new Error(`anvil did not start at ${url}`);
}

export default async function setup(): Promise<() => Promise<void>> {
  const env = { ...process.env, PATH: `${homedir()}/.foundry/bin:${process.env.PATH ?? ""}` };
  const contracts = resolve(import.meta.dirname, "../../../contracts");
  const build = spawnSync("forge", ["build"], { cwd: contracts, env, stdio: "inherit" });
  if (build.status !== 0) throw new Error("forge build failed");
  const anvil = spawn("anvil", ["--port", String(ANVIL_PORT), "--silent"], { env, stdio: "ignore" });
  await waitForRpc(`http://127.0.0.1:${ANVIL_PORT}`);
  return async () => {
    anvil.kill();
  };
}
```

`packages/sdk/src/encoding.ts`:
```ts
import { NO_EP, PIECE } from "./constants.js";

export type Meta = { side: number; castling: number; ep: number; halfmove: number; ply: number; status: number };
export type DecodedMove = { from: number; to: number; promo: number; kind: number };

const FEN_PIECE: Record<string, number> = {
  P: 1, N: 2, B: 3, R: 4, Q: 5, K: 6,
  p: 9, n: 10, b: 11, r: 12, q: 13, k: 14,
};
const PIECE_FEN = ".PNBRQK..pnbrqk.";

export function pieceAt(board: bigint, sq: number): number {
  return Number((board >> BigInt(sq * 4)) & 0xfn);
}

export function setPiece(board: bigint, sq: number, piece: number): bigint {
  const shift = BigInt(sq * 4);
  return (board & ~(0xfn << shift)) | (BigInt(piece) << shift);
}

export function unpackMeta(meta: bigint): Meta {
  return {
    side: Number(meta & 0xffn),
    castling: Number((meta >> 8n) & 0xffn),
    ep: Number((meta >> 16n) & 0xffn),
    halfmove: Number((meta >> 24n) & 0xffffn),
    ply: Number((meta >> 40n) & 0xffffn),
    status: Number((meta >> 56n) & 0xffn),
  };
}

export function packMeta(m: Meta): bigint {
  return (
    BigInt(m.side) |
    (BigInt(m.castling) << 8n) |
    (BigInt(m.ep) << 16n) |
    (BigInt(m.halfmove) << 24n) |
    (BigInt(m.ply) << 40n) |
    (BigInt(m.status) << 56n)
  );
}

export function withStatus(meta: bigint, status: number): bigint {
  return (meta & ~(0xffn << 56n)) | (BigInt(status) << 56n);
}

export function encodeMove(from: number, to: number, promo: number, kind: number): number {
  return (from | (to << 6) | (promo << 12) | (kind << 15)) >>> 0;
}

export function decodeMove(m: number): DecodedMove {
  return { from: m & 63, to: (m >>> 6) & 63, promo: (m >>> 12) & 7, kind: (m >>> 15) & 15 };
}

export function squareIndex(sq: string): number {
  if (!/^[a-h][1-8]$/.test(sq)) throw new Error(`not a square: ${sq}`);
  return sq.charCodeAt(0) - 97 + (sq.charCodeAt(1) - 49) * 8;
}

export function squareName(i: number): string {
  if (!Number.isInteger(i) || i < 0 || i > 63) throw new Error(`not a square index: ${i}`);
  return String.fromCharCode(97 + (i % 8)) + String.fromCharCode(49 + Math.floor(i / 8));
}

/** FEN → packed (board, meta) with status PLAYING; ply = (fullmove - 1) * 2 + side. */
export function fenToPosition(fen: string): { board: bigint; meta: bigint } {
  const [placement, side, castling, ep, half, full] = fen.split(" ");
  let board = 0n;
  placement.split("/").forEach((row, i) => {
    const rank = 7 - i;
    let file = 0;
    for (const ch of row) {
      if (ch >= "1" && ch <= "8") {
        file += Number(ch);
      } else {
        board |= BigInt(FEN_PIECE[ch]) << BigInt((rank * 8 + file) * 4);
        file++;
      }
    }
  });
  let rights = 0;
  if (castling.includes("K")) rights |= 1;
  if (castling.includes("Q")) rights |= 2;
  if (castling.includes("k")) rights |= 4;
  if (castling.includes("q")) rights |= 8;
  const sideN = side === "w" ? 0 : 1;
  const epSq = ep === "-" ? NO_EP : squareIndex(ep);
  const ply = (Number(full) - 1) * 2 + sideN;
  const meta =
    BigInt(sideN) |
    (BigInt(rights) << 8n) |
    (BigInt(epSq) << 16n) |
    (BigInt(Number(half)) << 24n) |
    (BigInt(ply) << 40n);
  return { board, meta };
}

/** Packed (board, meta) → FEN; fullmove = floor(ply / 2) + 1. */
export function positionToFen(board: bigint, meta: bigint): string {
  const m = unpackMeta(meta);
  const rows: string[] = [];
  for (let rank = 7; rank >= 0; rank--) {
    let row = "";
    let empty = 0;
    for (let file = 0; file < 8; file++) {
      const piece = pieceAt(board, rank * 8 + file);
      if (piece === PIECE.EMPTY) {
        empty++;
        continue;
      }
      if (empty > 0) {
        row += String(empty);
        empty = 0;
      }
      row += PIECE_FEN[piece];
    }
    if (empty > 0) row += String(empty);
    rows.push(row);
  }
  let castling = "";
  if (m.castling & 1) castling += "K";
  if (m.castling & 2) castling += "Q";
  if (m.castling & 4) castling += "k";
  if (m.castling & 8) castling += "q";
  const ep = m.ep < 64 ? squareName(m.ep) : "-";
  return `${rows.join("/")} ${m.side === 0 ? "w" : "b"} ${castling || "-"} ${ep} ${m.halfmove} ${Math.floor(m.ply / 2) + 1}`;
}
```

```ts
import { Chess } from "chess.js";
import type { Hex } from "viem";
import {
  FIFTY_MOVE_HALFMOVES,
  INITIAL_BOARD,
  INITIAL_META,
  KIND,
  MAX_PLY,
  NO_EP,
  PROMO,
  PROMO_LETTER,
  SIDE,
  STATUS,
  ZERO_HASH,
} from "./constants.js";
import {
  decodeMove,
  encodeMove,
  fenToPosition,
  packMeta,
  positionToFen,
  squareIndex,
  squareName,
  unpackMeta,
  withStatus,
} from "./encoding.js";
import type { Params, PlayerIndex, State } from "./types.js";

/** Result of applying a move; mirrors ChessRules.successor (ok flag + canonical next state). */
export type Transition = { ok: true; next: State } | { ok: false; reason: string };

const UCI = /^([a-h][1-8])([a-h][1-8])([nbrq])?$/;

export function initialState(channelId: Hex, p: Params): State {
  return {
    channelId,
    turnNum: 0n,
    prevHash: ZERO_HASH,
    balanceA: p.deposit,
    balanceB: p.deposit,
    gameIndex: 0,
    move: 0,
    board: INITIAL_BOARD,
    meta: INITIAL_META,
  };
}

export function statusOf(s: State): number {
  return unpackMeta(s.meta).status;
}

export function isCheckpoint(s: State): boolean {
  return decodeMove(s.move).kind === KIND.NEW_GAME;
}

export function isGameOver(s: State): boolean {
  const st = statusOf(s);
  return st === STATUS.WHITE_WON || st === STATUS.BLACK_WON || st === STATUS.DRAW;
}

export function playerOnMove(gameIndex: number, meta: bigint): PlayerIndex {
  const white = (gameIndex % 2) as PlayerIndex;
  return unpackMeta(meta).side === SIDE.WHITE ? white : ((1 - white) as PlayerIndex);
}

/** The player who signs the move state that follows `prev`. */
export function mover(prev: State): PlayerIndex {
  return playerOnMove(prev.gameIndex, prev.meta);
}

export function forfeitBalances(s: State, p: Params): [bigint, bigint] {
  return shiftStake(s.balanceA, s.balanceB, mover(s), p.stakePerGame);
}

export function fenOf(s: State): string {
  return positionToFen(s.board, s.meta);
}

/** Legal moves for the side to move, as UCI strings (e.g. "e2e4", "a7a8q"). */
export function legalMoves(s: State): string[] {
  const game = load(s);
  if (!game) return [];
  return game.moves({ verbose: true }).map((m) => `${m.from}${m.to}${m.promotion ?? ""}`);
}

/** Encodes a UCI or SAN move for the side to move in `s`. Throws if it cannot be parsed. */
export function parseMove(s: State, input: string, kind: number = KIND.NORMAL): number {
  const trimmed = input.trim();
  const u = UCI.exec(trimmed);
  if (u) return encodeMove(squareIndex(u[1]), squareIndex(u[2]), u[3] ? PROMO[u[3]] : 0, kind);
  const game = load(s);
  if (!game) throw new Error("position cannot be loaded");
  try {
    const m = game.move(trimmed);
    return encodeMove(squareIndex(m.from), squareIndex(m.to), m.promotion ? PROMO[m.promotion] : 0, kind);
  } catch {
    throw new Error(`unrecognised or illegal move: ${input}`);
  }
}

/** Mirrors ChessRules.successor exactly (see contracts/src/chess/ChessRules.sol). */
export function successor(prev: State, move: number, p: Params): Transition {
  const next: State = { ...prev, turnNum: prev.turnNum + 1n, prevHash: ZERO_HASH, move };
  const { kind } = decodeMove(move);
  const st = statusOf(prev);
  const inProgress = st === STATUS.PLAYING || st === STATUS.DRAW_OFFERED;

  if (kind === KIND.NEW_GAME) {
    if (inProgress || move !== encodeMove(0, 0, 0, KIND.NEW_GAME)) return fail("new game only after a finished game");
    if (prev.balanceA < p.stakePerGame || prev.balanceB < p.stakePerGame) return fail("a balance is below the stake");
    return ok({ ...next, gameIndex: prev.gameIndex + 1, board: INITIAL_BOARD, meta: INITIAL_META });
  }
  if (!inProgress) return fail("the game is over");
  if (kind === KIND.NORMAL || kind === KIND.NORMAL_OFFER_DRAW) return normalMove(prev, move, kind, p, next);
  if (move !== encodeMove(0, 0, 0, kind)) return fail("non-canonical move encoding");
  if (kind === KIND.RESIGN) {
    const whiteResigns = unpackMeta(prev.meta).side === SIDE.WHITE;
    const [balanceA, balanceB] = shiftStake(prev.balanceA, prev.balanceB, mover(prev), p.stakePerGame);
    return ok({
      ...next,
      meta: withStatus(prev.meta, whiteResigns ? STATUS.BLACK_WON : STATUS.WHITE_WON),
      balanceA,
      balanceB,
    });
  }
  if (kind === KIND.ACCEPT_DRAW) {
    if (st !== STATUS.DRAW_OFFERED) return fail("no draw offer to accept");
    return ok({ ...next, meta: withStatus(prev.meta, STATUS.DRAW) });
  }
  if (kind === KIND.CLAIM_STALEMATE) {
    const game = load(prev);
    if (!game || game.inCheck() || game.moves().length > 0) return fail("not a stalemate");
    return ok({ ...next, meta: withStatus(prev.meta, STATUS.DRAW) });
  }
  return fail("unknown move kind");
}

function normalMove(prev: State, move: number, kind: number, p: Params, next: State): Transition {
  const { from, to, promo } = decodeMove(move);
  if (move !== encodeMove(from, to, promo, kind)) return fail("non-canonical move encoding");
  if (promo === 1 || promo > 5) return fail("bad promotion piece");
  const game = load(prev);
  if (!game) return fail("position cannot be loaded");
  let played;
  try {
    played = game.move({ from: squareName(from), to: squareName(to), ...(promo ? { promotion: PROMO_LETTER[promo] } : {}) });
  } catch {
    return fail("illegal move");
  }
  // chess.js ignores a promotion suffix on a non-promotion move; the contract rejects it.
  if ((promo !== 0) !== (played.promotion !== undefined)) return fail("promotion does not match the move");

  const prevMeta = unpackMeta(prev.meta);
  const afterMeta = unpackMeta(fenToPosition(game.fen()).meta);
  const meta = {
    side: prevMeta.side === SIDE.WHITE ? SIDE.BLACK : SIDE.WHITE,
    castling: afterMeta.castling,
    // The contract always records the skipped square after a double push; chess.js omits it when no capture exists.
    ep: played.flags.includes("b") ? (from + to) / 2 : NO_EP,
    halfmove: afterMeta.halfmove,
    ply: prevMeta.ply + 1,
    status: kind === KIND.NORMAL_OFFER_DRAW ? STATUS.DRAW_OFFERED : STATUS.PLAYING,
  };
  let { balanceA, balanceB } = prev;
  if (game.isInsufficientMaterial()) {
    meta.status = STATUS.DRAW;
  } else if (meta.halfmove >= FIFTY_MOVE_HALFMOVES || meta.ply >= MAX_PLY) {
    // A checkmate delivered by the limiting move still wins; otherwise the game is drawn.
    if (game.inCheck() && game.moves().length === 0) {
      meta.status = prevMeta.side === SIDE.WHITE ? STATUS.WHITE_WON : STATUS.BLACK_WON;
      [balanceA, balanceB] = shiftStake(prev.balanceA, prev.balanceB, playerOnMove(prev.gameIndex, packMeta(meta)), p.stakePerGame);
    } else {
      meta.status = STATUS.DRAW;
    }
  }
  return ok({ ...next, board: fenToPosition(game.fen()).board, meta: packMeta(meta), balanceA, balanceB });
}

function load(s: State): Chess | null {
  try {
    return new Chess(positionToFen(s.board, s.meta));
  } catch {
    return null;
  }
}

function shiftStake(a: bigint, b: bigint, loser: PlayerIndex, stake: bigint): [bigint, bigint] {
  if (loser === 0) {
    const x = stake < a ? stake : a;
    return [a - x, b + x];
  }
  const y = stake < b ? stake : b;
  return [a + y, b - y];
}

function ok(next: State): Transition {
  return { ok: true, next };
}

function fail(reason: string): Transition {
  return { ok: false, reason };
}
```

```ts
/** abi.encode(params) — the payload of ChannelHub.deposit(bytes). */
export function encodeParams(p: Params): Hex {
  return encodeAbiParameters([{ type: "tuple", components: PARAMS }], [p]);
}

/** keccak256(abi.encode(chainId, hub, params)) — ChannelHub.channelId. */
export function channelId(chainId: number, hub: Address, p: Params): Hex {
  return keccak256(
    encodeAbiParameters([{ type: "uint256" }, { type: "address" }, { type: "tuple", components: PARAMS }], [
      BigInt(chainId),
      hub,
      p,
    ]),
  );
}

export function encodeSignedState(ss: SignedState): Hex {
  return encodeAbiParameters([{ type: "tuple", components: SIGNED }], [ss]);
}

export function decodeSignedState(data: Hex): SignedState {
  const [ss] = decodeAbiParameters([{ type: "tuple", components: SIGNED }], data);
  return { state: { ...ss.state }, sigA: ss.sigA, sigB: ss.sigB };
}

export function encodeProof(proof: Proof): Hex {
  return encodeAbiParameters([{ type: "tuple", components: PROOF }], [proof]);
}

export function decodeProof(data: Hex): Proof {
  const [p] = decodeAbiParameters([{ type: "tuple", components: PROOF }], data);
  const toSigned = (x: typeof p.prev): SignedState => ({ state: { ...x.state }, sigA: x.sigA, sigB: x.sigB });
  return { hasPrev: p.hasPrev, prev: toSigned(p.prev), latest: toSigned(p.latest) };
}
```

```ts
/** A hub call that would revert; `errorName` is the decoded custom error (e.g. "BadSignature") when known. */
export class HubRevertError extends Error {
  constructor(
    readonly errorName: string | undefined,
    underlying: unknown,
  ) {
    super(
      errorName
        ? `hub reverted: ${errorName}`
        : `hub call failed: ${underlying instanceof Error ? underlying.message : String(underlying)}`,
      { cause: underlying },
    );
    this.name = "HubRevertError";
  }
}

const REVERT_ABI = [...channelHubAbi, ...mockUsdcAbi];

/** Extracts the custom-error name from a viem call/transaction error, if the revert data is decodable. */
export function decodeRevert(err: unknown): string | undefined {
  if (!(err instanceof BaseError)) return undefined;
  const withData = err.walk((e) => typeof (e as { data?: unknown }).data === "string") as { data?: Hex } | null;
  const data = withData?.data;
  if (!data || data === "0x") return undefined;
  try {
    const decoded = decodeErrorResult({ abi: REVERT_ABI, data });
    return decoded.errorName === "Error" ? String(decoded.args?.[0]) : decoded.errorName;
  } catch {
    return undefined;
  }
}

  constructor(
    readonly hub: Address,
    readonly client: PublicClient,
  ) {}

  approve(sender: TxSender, token: Address, amount: bigint): Promise<TransactionReceipt> {

  }

  respond(sender: TxSender, proof: Proof): Promise<TransactionReceipt> {
    return this.call(sender, encodeFunctionData({ abi: channelHubAbi, functionName: "respond", args: [encodeProof(proof)] }));
  }

  timeout(sender: TxSender, id: Hex): Promise<TransactionReceipt> {
    return this.call(sender, encodeFunctionData({ abi: channelHubAbi, functionName: "timeout", args: [id] }));
  }

  reclaim(sender: TxSender, id: Hex): Promise<TransactionReceipt> {
    return this.call(sender, encodeFunctionData({ abi: channelHubAbi, functionName: "reclaim", args: [id] }));
  }

    return this.call(sender, encodeFunctionData({ abi: channelHubAbi, functionName: "claim", args: [to] }));
  }

  async channelInfo(id: Hex): Promise<ChannelInfo> {
    const r = await this.client.readContract({ address: this.hub, abi: channelHubAbi, functionName: "channelInfo", args: [id] });
    return { ...r, phase: PHASE[r.phase] };
  }

  async registeredState(id: Hex): Promise<State> {
    const s = await this.client.readContract({ address: this.hub, abi: channelHubAbi, functionName: "registeredState", args: [id] });
    return { ...s };
  }

  async channelParams(id: Hex): Promise<Params> {
    const p = await this.client.readContract({ address: this.hub, abi: channelHubAbi, functionName: "channelParams", args: [id] });
    return { ...p };
  }

  owed(addr: Address): Promise<bigint> {
    return this.client.readContract({ address: this.hub, abi: channelHubAbi, functionName: "owed", args: [addr] });
  }

  /** Challenged/Responded events for a channel in chain order, with the signed state each one carries. */
  async disputeEvents(id: Hex, fromBlock: bigint = 0n): Promise<DisputeEvent[]> {
    const [challenged, responded] = await Promise.all([
      this.client.getContractEvents({ address: this.hub, abi: channelHubAbi, eventName: "Challenged", args: { channelId: id }, fromBlock }),
      this.client.getContractEvents({ address: this.hub, abi: channelHubAbi, eventName: "Responded", args: { channelId: id }, fromBlock }),
    ]);
    const events: DisputeEvent[] = [
      ...challenged.map((l) => ({
        kind: "Challenged" as const,
        blockNumber: l.blockNumber,
        logIndex: l.logIndex,
        turnNum: l.args.turnNum as bigint,
        signed: decodeSignedState(l.args.signedState as Hex),
        challenger: Number(l.args.challenger),
        deadline: l.args.deadline as bigint,
      })),
      ...responded.map((l) => ({
        kind: "Responded" as const,
        blockNumber: l.blockNumber,
        logIndex: l.logIndex,
        turnNum: l.args.turnNum as bigint,
        signed: decodeSignedState(l.args.signedState as Hex),
      })),
    ];
    return events.sort((x, y) =>
      x.blockNumber === y.blockNumber ? x.logIndex - y.logIndex : x.blockNumber < y.blockNumber ? -1 : 1,
    );
  }

  private call(sender: TxSender, data: Hex): Promise<TransactionReceipt> {
    return this.write(sender, this.hub, data);
  }

  /** Simulates first so reverts surface as named errors, then sends and waits for success. */
  private async write(sender: TxSender, to: Address, data: Hex): Promise<TransactionReceipt> {
    try {
      await this.client.call({ account: sender.address, to, data });
    } catch (err) {
      throw new HubRevertError(decodeRevert(err), err);
    }
    const hash = await sender.send({ to, data });
    const receipt = await this.client.waitForTransactionReceipt({ hash });
    if (receipt.status !== "success") throw new HubRevertError(undefined, new Error(`transaction ${hash} reverted`));
    return receipt;
  }
}
```

```ts
import type { Hex } from "viem";
import type { SignedState } from "./types.js";

/** Everything a session needs to resume after a crash. Saved before any signature leaves the session. */
export type SessionSnapshot = {
  channelId: Hex;
  /** Latest state that is supported: opening, fully signed checkpoint, or a move signed by its mover. */
  latest: SignedState;
  /** The state before `latest`, carrying the signature that proves the other player endorsed it. */
  prev: SignedState | null;
  /** NEW_GAME this player proposed and signed, awaiting the opponent's countersignature. */
  pendingCheckpoint: SignedState | null;
  /** NEW_GAME the opponent proposed and signed, awaiting this player's decision. */
  incomingCheckpoint: SignedState | null;
  /** Highest turnNum this player has signed (equivocation guard). */
  lastSignedTurn: bigint | null;
  /** State this player signed Close for; nothing is signed afterwards. */
  closeState: SignedState | null;
  /** Close signatures by player index ("0x" = absent). */
  closeSigs: [Hex, Hex];
};

export interface SessionStore {
  save(snapshot: SessionSnapshot): Promise<void>;
}

/** In-memory store for tests and ephemeral sessions. The daemon (Plan 3) provides a file-backed store. */
export class MemoryStore implements SessionStore {
  readonly snapshots: SessionSnapshot[] = [];

  async save(snapshot: SessionSnapshot): Promise<void> {
    this.snapshots.push(structuredClone(snapshot));
  }

  get last(): SessionSnapshot | undefined {
    return this.snapshots.at(-1);
  }
}
```

```ts
import type { Hex } from "viem";
import { privateKeyToAccount } from "viem/accounts";
import { EMPTY_SIGNED, channelId, unsigned } from "./abiCodec.js";
import { initialState, isCheckpoint, isGameOver, legalMoves, mover, parseMove, successor } from "./chess.js";
import { KIND } from "./constants.js";
import { encodeMove } from "./encoding.js";
import {
  hashState,
  recoverCloseSigner,
  recoverStateSigner,
  signClose,
  signState,
  type ArenaDomain,
} from "./eip712.js";
import type { SessionSnapshot, SessionStore } from "./store.js";
import type { Params, PlayerIndex, Proof, SignedState, State } from "./types.js";

export class ArenaProtocolError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "ArenaProtocolError";
  }
}

export type CloseSignature = { stateHash: Hex; by: PlayerIndex; sig: Hex };

export type SessionConfig = {
  params: Params;
  me: PlayerIndex;
  sessionKey: Hex;
  domain: ArenaDomain;
  store: SessionStore;
};

const NO_SIG: Hex = "0x";

/**
 * One player's view of one channel. Validates every incoming state exactly as the hub would, signs only through
 * an equivocation guard, and persists before any signature is returned (spec §7, §12).
 */
export class ChannelSession {
  readonly params: Params;
  readonly me: PlayerIndex;
  readonly opponent: PlayerIndex;
  readonly id: Hex;
  private readonly domain: ArenaDomain;
  private readonly key: Hex;
  private readonly store: SessionStore;
  private data: SessionSnapshot;

  private constructor(cfg: SessionConfig, data: SessionSnapshot) {
    if (privateKeyToAccount(cfg.sessionKey).address.toLowerCase() !== cfg.params.signers[cfg.me].toLowerCase()) {
      throw new ArenaProtocolError("session key does not match params.signers[me]");
    }
    this.params = cfg.params;
    this.me = cfg.me;
    this.opponent = cfg.me === 0 ? 1 : 0;
    this.domain = cfg.domain;
    this.key = cfg.sessionKey;
    this.store = cfg.store;
    this.id = data.channelId;
    this.data = data;
  }

  static async create(cfg: SessionConfig): Promise<ChannelSession> {
    const id = channelId(cfg.domain.chainId, cfg.domain.hub, cfg.params);
    const session = new ChannelSession(cfg, {
      channelId: id,
      latest: unsigned(initialState(id, cfg.params)),
      prev: null,
      pendingCheckpoint: null,
      incomingCheckpoint: null,
      lastSignedTurn: null,
      closeState: null,
      closeSigs: [NO_SIG, NO_SIG],
    });
    await session.persist();
    return session;
  }

  static restore(cfg: SessionConfig, snapshot: SessionSnapshot): ChannelSession {
    return new ChannelSession(cfg, structuredClone(snapshot));
  }

  get latest(): SignedState {
    return this.data.latest;
  }

  get isClosing(): boolean {
    return this.data.closeState !== null;
  }

  snapshot(): SessionSnapshot {
    return structuredClone(this.data);
  }

  isMyTurn(): boolean {
    const s = this.data.latest.state;
    return !this.isClosing && !isGameOver(s) && this.endorsed(this.data.latest) && mover(s) === this.me;
  }

  legalMoves(): string[] {
    return this.isMyTurn() ? legalMoves(this.data.latest.state) : [];
  }

  move(input: string, opts: { offerDraw?: boolean } = {}): Promise<SignedState> {
    if (!this.isMyTurn()) return Promise.reject(new ArenaProtocolError("not your turn"));
    const kind = opts.offerDraw ? KIND.NORMAL_OFFER_DRAW : KIND.NORMAL;
    let encoded: number;
    try {
      encoded = parseMove(this.data.latest.state, input, kind);
    } catch (err) {
      return Promise.reject(new ArenaProtocolError((err as Error).message));
    }
    return this.act(encoded);
  }

  resign(): Promise<SignedState> {
    return this.act(encodeMove(0, 0, 0, KIND.RESIGN));
  }

  acceptDraw(): Promise<SignedState> {
    return this.act(encodeMove(0, 0, 0, KIND.ACCEPT_DRAW));
  }

  claimStalemate(): Promise<SignedState> {
    return this.act(encodeMove(0, 0, 0, KIND.CLAIM_STALEMATE));
  }

  async proposeNewGame(): Promise<SignedState> {
    this.assertNotClosing();
    if (this.data.pendingCheckpoint) return this.data.pendingCheckpoint;
    if (this.data.incomingCheckpoint) return this.countersignNewGame();
    if (!isGameOver(this.data.latest.state)) throw new ArenaProtocolError("the game is still in progress");
    const signed = await this.signAsMe(this.next(encodeMove(0, 0, 0, KIND.NEW_GAME)));
    this.data.pendingCheckpoint = signed;
    await this.persist();
    return signed;
  }

  async countersignNewGame(): Promise<SignedState> {
    const incoming = this.data.incomingCheckpoint;
    if (!incoming) throw new ArenaProtocolError("no new-game proposal to countersign");
    const signed = await this.signAsMe(incoming.state, incoming);
    this.advance(signed);
    this.data.incomingCheckpoint = null;
    await this.persist();
    return signed;
  }

  /** Validates and records an opponent message (a move, or a NEW_GAME proposal/countersignature). */
  async receive(msg: SignedState): Promise<"move" | "checkpoint-proposed" | "checkpoint-complete"> {
    this.assertNotClosing();
    const s = msg.state;
    const latest = this.data.latest.state;
    if (s.channelId !== this.id) throw new ArenaProtocolError("wrong channel");
    if (s.turnNum !== latest.turnNum + 1n) {
      throw new ArenaProtocolError(`unexpected turn ${s.turnNum}; expected ${latest.turnNum + 1n}`);
    }
    const expected = this.next(s.move);
    if (hashState(expected, this.domain) !== hashState(s, this.domain)) {
      throw new ArenaProtocolError("state does not match the rules");
    }
    const oppSig = this.opponent === 0 ? msg.sigA : msg.sigB;
    if (!(await this.signedBy(this.opponent, s, oppSig))) {
      throw new ArenaProtocolError("missing or invalid opponent signature");
    }

    if (isCheckpoint(s)) {
      const pending = this.data.pendingCheckpoint;
      if (pending && hashState(pending.state, this.domain) === hashState(s, this.domain)) {
        this.advance({
          state: s,
          sigA: pending.sigA !== NO_SIG ? pending.sigA : msg.sigA,
          sigB: pending.sigB !== NO_SIG ? pending.sigB : msg.sigB,
        });
        this.data.pendingCheckpoint = null;
        await this.persist();
        return "checkpoint-complete";
      }
      this.data.incomingCheckpoint = this.withOnly(this.opponent, s, oppSig);
      await this.persist();
      return "checkpoint-proposed";
    }

    if (!this.endorsed(this.data.latest)) throw new ArenaProtocolError("the new-game checkpoint is not fully signed");
    if (mover(latest) !== this.opponent) throw new ArenaProtocolError("it is not the opponent's turn");
    this.advance(this.withOnly(this.opponent, s, oppSig));
    await this.persist();
    return "move";
  }

  /** Signs Close for the latest state. Only between games; afterwards this session signs nothing else. */
  async signClose(): Promise<CloseSignature> {
    const current = this.data.latest;
    const s = current.state;
    if (this.data.closeState) {
      if (hashState(this.data.closeState.state, this.domain) !== hashState(s, this.domain)) {
        throw new ArenaProtocolError("already signed Close for another state");
      }
      return { stateHash: hashState(s, this.domain), by: this.me, sig: this.data.closeSigs[this.me] };
    }
    if (this.data.pendingCheckpoint) {
      throw new ArenaProtocolError("a new-game proposal is pending; close on the checkpoint once countersigned, or challenge");
    }
    const betweenGames = s.turnNum === 0n || (isCheckpoint(s) && this.endorsed(current)) || isGameOver(s);
    if (!betweenGames) throw new ArenaProtocolError("can only close between games");
    if (this.data.lastSignedTurn !== null && this.data.lastSignedTurn > s.turnNum) {
      throw new ArenaProtocolError("already signed a later state");
    }
    const sig = await signClose(this.key, s, this.domain);
    this.data.closeState = current;
    this.data.closeSigs[this.me] = sig;
    await this.persist();
    return { stateHash: hashState(s, this.domain), by: this.me, sig };
  }

  async receiveClose(cs: CloseSignature): Promise<void> {
    if (cs.by !== this.opponent) throw new ArenaProtocolError("close signature is not from the opponent");
    const target = (this.data.closeState ?? this.data.latest).state;
    if (cs.stateHash !== hashState(target, this.domain)) {
      throw new ArenaProtocolError("close signature is for a different state");
    }
    const signer = await recoverCloseSigner(target, cs.sig, this.domain);
    if (signer.toLowerCase() !== this.params.signers[this.opponent].toLowerCase()) {
      throw new ArenaProtocolError("invalid close signature");
    }
    this.data.closeSigs[this.opponent] = cs.sig;
    await this.persist();
  }

  /** The SignedState to pass to ChannelHub.closeCooperative once both Close signatures exist. */
  closeTransaction(): SignedState | null {
    const target = this.data.closeState;
    const [sigA, sigB] = this.data.closeSigs;
    if (!target || sigA === NO_SIG || sigB === NO_SIG) return null;
    return { state: target.state, sigA, sigB };
  }

  /** Proof that the latest state is supported (spec §4.3), for challenge() or respond(). */
  challengeProof(): Proof {
    const latest = this.data.latest;
    const fullySigned = latest.sigA !== NO_SIG && latest.sigB !== NO_SIG;
    if (latest.state.turnNum === 0n || fullySigned) return { hasPrev: false, prev: EMPTY_SIGNED, latest };
    if (!this.data.prev) throw new ArenaProtocolError("no endorsed predecessor for the latest state");
    return { hasPrev: true, prev: this.data.prev, latest };
  }

  /** Adopts a newer state registered on-chain (Challenged/Responded event). Returns false if not newer. */
  async ingestOnChain(signed: SignedState): Promise<boolean> {
    if (signed.state.channelId !== this.id) throw new ArenaProtocolError("wrong channel");
    if (signed.state.turnNum <= this.data.latest.state.turnNum) return false;
    const chains = hashState(this.data.latest.state, this.domain) === signed.state.prevHash;
    this.data.prev = chains ? this.data.latest : null;
    this.data.latest = signed;
    this.data.pendingCheckpoint = null;
    this.data.incomingCheckpoint = null;
    await this.persist();
    return true;
  }

  private async act(move: number): Promise<SignedState> {
    if (!this.isMyTurn()) throw new ArenaProtocolError("not your turn");
    const signed = await this.signAsMe(this.next(move));
    this.advance(signed);
    await this.persist();
    return signed;
  }

  /** Canonical successor of the latest state with prevHash set. Throws if the move is illegal. */
  private next(move: number): State {
    const r = successor(this.data.latest.state, move, this.params);
    if (!r.ok) throw new ArenaProtocolError(`illegal: ${r.reason}`);
    return { ...r.next, prevHash: hashState(this.data.latest.state, this.domain) };
  }

  private async signAsMe(state: State, base?: SignedState): Promise<SignedState> {
    this.assertNotClosing();
    const last = this.data.lastSignedTurn;
    if (last !== null && state.turnNum <= last) {
      throw new ArenaProtocolError(`refusing to sign turn ${state.turnNum}: already signed turn ${last}`);
    }
    const sig = await signState(this.key, state, this.domain);
    this.data.lastSignedTurn = state.turnNum;
    const out: SignedState = base ? { ...base, state } : unsigned(state);
    if (this.me === 0) out.sigA = sig;
    else out.sigB = sig;
    return out;
  }

  private advance(next: SignedState): void {
    this.data.prev = this.data.latest;
    this.data.latest = next;
  }

  private endorsed(ss: SignedState): boolean {
    return !isCheckpoint(ss.state) || (ss.sigA !== NO_SIG && ss.sigB !== NO_SIG);
  }

  private withOnly(player: PlayerIndex, state: State, sig: Hex): SignedState {
    return player === 0 ? { state, sigA: sig, sigB: NO_SIG } : { state, sigA: NO_SIG, sigB: sig };
  }

  private async signedBy(player: PlayerIndex, state: State, sig: Hex): Promise<boolean> {
    if (sig === NO_SIG) return false;
    try {
      const who = await recoverStateSigner(state, sig, this.domain);
      return who.toLowerCase() === this.params.signers[player].toLowerCase();
    } catch {
      return false;
    }
  }

  private assertNotClosing(): void {
    if (this.isClosing) throw new ArenaProtocolError("channel is closing; no further states are signed or accepted");
  }

  private async persist(): Promise<void> {
    await this.store.save(this.data);
  }
}
```

```ts
import { describe, expect, it } from "vitest";
import { generatePrivateKey } from "viem/accounts";
import {
  ChannelSession,
  HubClient,
  HubRevertError,
  LocalKeyTxSender,
  MemoryStore,
  signState,
  type SessionConfig,
} from "../src/index.js";
import { ANVIL_KEYS, CHAIN, RPC, deployArena, increaseTime, mintUsdc, now, setEthBalance, usdcBalance } from "./helpers/chain.js";
import { SCHOLARS_MATE, makeParams } from "./helpers/fixtures.js";

const START = 10_000_000n;
const MAX = 2n ** 255n;

async function arena(salt: string) {
  const env = await deployArena();
  const alice = new LocalKeyTxSender(ANVIL_KEYS[1], RPC, CHAIN);
  const bob = new LocalKeyTxSender(ANVIL_KEYS[2], RPC, CHAIN);
  const sessionKeys = [generatePrivateKey(), generatePrivateKey()] as const;
  const params = makeParams({
    participants: [alice.address, bob.address],
    sessionKeys,
    rules: env.rules,
    feeRecipient: env.host,
    fundingDeadline: (await now()) + 3600n,
    salt,
  });
  const hub = new HubClient(env.hub, env.pub);
  for (const who of [alice, bob]) {
    await mintUsdc(env.usdc, who.address, START);
    await hub.approve(who, env.usdc, MAX);
  }
  const cfg = (me: 0 | 1): SessionConfig => ({ params, me, sessionKey: sessionKeys[me], domain: env.domain, store: new MemoryStore() });
  return { env, hub, alice, bob, params, sessionKeys, cfg };
}

async function open(x: Awaited<ReturnType<typeof arena>>) {
  await x.hub.deposit(x.alice, x.params);
  await x.hub.deposit(x.bob, x.params);
  const a = await ChannelSession.create(x.cfg(0));
  const b = await ChannelSession.create(x.cfg(1));
  expect((await x.hub.channelInfo(a.id)).phase).toBe("Open");
  return { a, b };
}

async function play(a: ChannelSession, b: ChannelSession, moves: string[]) {
  for (const m of moves) {
    const [mover, other] = a.isMyTurn() ? [a, b] : [b, a];
    await other.receive(await mover.move(m));
  }
}

describe("channel lifecycle on Anvil", () => {
  it("plays two games off-chain and closes cooperatively with Close signatures", async () => {
    const x = await arena("coop");
    const { a, b } = await open(x);

    await play(a, b, SCHOLARS_MATE); // game 0: A white mates
    await a.receive(await b.resign());
    const proposal = await a.proposeNewGame();
    await b.receive(proposal);
    await a.receive(await b.countersignNewGame());
    await play(a, b, SCHOLARS_MATE); // game 1: B white mates
    await b.receive(await a.resign());

    await b.receiveClose(await a.signClose());
    await a.receiveClose(await b.signClose());
    const tx = a.closeTransaction();
    expect(tx).not.toBeNull();
    await x.hub.closeCooperative(x.alice, tx!);

    expect((await x.hub.channelInfo(a.id)).phase).toBe("Finalized");
    expect(await usdcBalance(x.env.usdc, x.alice.address)).toBe(START - x.params.feePerPlayer);
    expect(await usdcBalance(x.env.usdc, x.bob.address)).toBe(START - x.params.feePerPlayer);
    expect(await usdcBalance(x.env.usdc, x.env.host)).toBe(2n * x.params.feePerPlayer);
  });

  it("challenges via a session key, answers on-chain, resumes, and forfeits a staller on timeout", async () => {
    const x = await arena("dispute");
    const { a, b } = await open(x);
    const aliceSessionSender = new LocalKeyTxSender(x.sessionKeys[0], RPC, CHAIN);
    await setEthBalance(aliceSessionSender.address, 10n ** 18n);

    const e4 = await a.move("e2e4");
    await b.receive(e4); // Bob goes quiet instead of answering
    await x.hub.challenge(aliceSessionSender, a.challengeProof());
    expect((await x.hub.channelInfo(a.id)).phase).toBe("Challenged");

    // Bob's watchtower sees the challenge, answers on-chain; Alice adopts the answer from the event.
    const events = await x.hub.disputeEvents(b.id);
    expect(events.map((e) => e.kind)).toEqual(["Challenged"]);
    expect(await b.ingestOnChain(events[0].signed)).toBe(false); // Bob already had it
    await b.move("e7e5");
    await x.hub.respond(x.bob, b.challengeProof());
    const responded = (await x.hub.disputeEvents(a.id)).at(-1)!;
    expect(responded.kind).toBe("Responded");
    expect(await a.ingestOnChain(responded.signed)).toBe(true);
    expect(a.isMyTurn()).toBe(true);
    expect((await x.hub.channelInfo(a.id)).phase).toBe("Open");

    // Now Alice stalls; Bob challenges the registered state and wins the stake on timeout.
    await x.hub.challenge(x.bob, b.challengeProof());
    await expect(x.hub.timeout(x.alice, a.id)).rejects.toThrow(/TooEarly/);
    await increaseTime(Number(x.params.challengeTimeout));
    await x.hub.timeout(x.alice, a.id);
    const d = x.params.deposit;
    const f = x.params.feePerPlayer;
    const s = x.params.stakePerGame;
    expect(await usdcBalance(x.env.usdc, x.alice.address)).toBe(START - d - f + (d - s));
    expect(await usdcBalance(x.env.usdc, x.bob.address)).toBe(START - d - f + (d + s));
  });

  it("reclaims an unfunded channel after the deadline", async () => {
    const x = await arena("reclaim");
    await x.hub.deposit(x.alice, x.params);
    const a = await ChannelSession.create(x.cfg(0));
    await expect(x.hub.reclaim(x.alice, a.id)).rejects.toThrow(/TooEarly/);
    await increaseTime(3601);
    await x.hub.reclaim(x.alice, a.id);
    expect(await usdcBalance(x.env.usdc, x.alice.address)).toBe(START);
    expect((await x.hub.channelInfo(a.id)).phase).toBe("Reclaimed");
  });

  it("surfaces hub custom errors by name", async () => {
    const x = await arena("errors");
    const { a, b } = await open(x);
    await b.receive(await a.move("e2e4"));
    await a.receive(await b.resign());
    // State co-signatures are not a close intent: the hub rejects them.
    const s = a.latest.state;
    const cosigned = {
      state: s,
      sigA: await signState(x.sessionKeys[0], s, x.env.domain),
      sigB: await signState(x.sessionKeys[1], s, x.env.domain),
    };
    const err = await x.hub.closeCooperative(x.alice, cosigned).catch((e: unknown) => e);
    expect(err).toBeInstanceOf(HubRevertError);
    expect((err as HubRevertError).errorName).toBe("BadSignature");
    await expect(x.hub.deposit(x.alice, x.params)).rejects.toThrow(/WrongPhase/);
  });
});
```

```markdown
# @arena/sdk

Protocol library for the Agent Chess Arena (spec: `docs/superpowers/specs/2026-09-24-agent-chess-arena-design.md`).

- `encoding` / `constants` — packed board, meta and move encodings (identical to `contracts/README.md`).
- `chess` — `successor(prev, move, params)`: a chess.js-backed mirror of `ChessRules.successor`, checked for
  parity against the deployed contract on every test run.
- `eip712` — `hashState`, `hashClose`, `signState`, `signClose` (domain `AgentArena`/`1`).
- `abiCodec` — `encodeParams` (payload of `deposit(bytes)`), `channelId`, SignedState/Proof codecs.
- `ChannelSession` — one player's channel state machine. It enforces:
  - every incoming state equals the rules' successor, is signed by the right session key and extends the latest state;
  - a move is only accepted on a NEW_GAME checkpoint that carries both signatures;
  - it never signs two states with the same turn number, and persists before returning any signature;
  - Close is signed only for the latest state, between games, with nothing later signed — and then signing stops.
- `HubClient` — typed ChannelHub calls through a `TxSender`; reverts surface as `HubRevertError.errorName`.
- `LocalKeyTxSender` — sends from a local key (participant wallet on Anvil, or a session key for disputes).
```
