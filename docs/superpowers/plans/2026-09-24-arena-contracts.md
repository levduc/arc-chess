# Arena Contracts Implementation Plan (Plan 1 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and fully test the on-chain half of the Agent Chess Arena: the generic `ChannelHub` state-channel adjudicator, the `IGameRules` template interface, and the `ChessRules` template (full chess legality), verified against chess.js with a differential test.

**Architecture:** `ChannelHub` escrows USDC per channel, verifies EIP-712 states signed by per-channel session keys, and runs force-move disputes (challenge → respond / timeout) with a per-player challenge cooldown. All game knowledge lives behind `IGameRules`; `ChessRules` implements it over a packed board (`uint256`, 4 bits per square) and packed metadata (`uint256`). Legality is implemented in two internal libraries (`ChessBoard` for encoding, `ChessMoves` for rules) and cross-checked against chess.js via ABI-encoded test vectors generated by a small TypeScript tool.

**Tech Stack:** Foundry (forge/anvil/cast), Solidity 0.8.28, OpenZeppelin Contracts v5.7.0, forge-std v1.16.2; TypeScript tool with chess.js 1.4.0, viem 2.56.9, tsx 4.23.15; pnpm 12.6.0 workspaces.

**Spec:** `docs/superpowers/specs/2026-09-24-agent-chess-arena-design.md` (rev 2). Read §4 (Contracts), §7 (Error handling), §8 items 1–5 (Testing), §9 (Security model) before starting.

**Plan series:** 1 Contracts (this) → 2 SDK → 3 Player daemon + CLI → 4 Host server → 5 Web board + skill.md + e2e → 6 Arc Testnet + Circle wallets. The Arc spike (spec §10 step 0) needs a human with a Circle agent wallet and runs in parallel with this plan; its results may change only the encoding notes in Task 12.

## Refinements to the spec made by this plan

These are deliberate, small, and must be reflected back into the spec in Task 12:

1. `IGameRules` gains `isCheckpoint`, `isGameOver`, `forfeitBalances` so `ChannelHub` stays game-agnostic; argument order follows spec (`validTransition(prev, next, p)`, `mover(prev, p)`). `ChessRules` additionally exposes `successor(prev, move, p)` (canonical next state), used by tests and later by the SDK for parity.
2. Move kind `NONE = 0` is added for the opening state; the other kinds are `NORMAL=1, NORMAL_OFFER_DRAW=2, RESIGN=3, ACCEPT_DRAW=4, CLAIM_STALEMATE=5, NEW_GAME=6`.
3. Payouts are push-with-fallback: if a USDC transfer to a recipient fails (e.g. USDC-blocklisted address), the amount is credited to `owed[recipient]` and claimable via `claim(to)`. This prevents one blocked participant from locking the counterparty's funds.
4. `challenge` accepts a state whose `turnNum` equals the registered one only if it is the identical state (same hash); this lets the waiting player challenge after a response without allowing equivocation.
5. A checkmate delivered on the move that triggers the 50-move or 300-ply limit is scored as a win, not a draw.

## Global Constraints

- Solidity `0.8.28`, `evm_version = "cancun"`, `via_ir = true`, optimizer on, 200 runs.
- OpenZeppelin Contracts `v5.7.0`, forge-std `v1.16.2`; JS deps pinned exactly: `chess.js@1.4.0`, `viem@2.56.9`, `tsx@4.23.15`; `pnpm@12.6.0`; Node ≥ 20.
- No upgradeability, no proxies, no `selfdestruct`, no `delegatecall`.
- EIP-712 domain: `name = "AgentArena"`, `version = "1"`, `chainId`, `verifyingContract = ChannelHub`.
- State typehash string exactly: `State(bytes32 channelId,uint64 turnNum,bytes32 prevHash,uint256 balanceA,uint256 balanceB,uint32 gameIndex,uint32 move,uint256 board,uint256 meta)`.
- `channelId = keccak256(abi.encode(block.chainid, address(hub), params))`.
- USDC has 6 decimals. Default `feePerPlayer = 5_000` (\$0.005, i.e. \$0.01 per channel). `MIN_TIMEOUT = 60`, `MAX_TIMEOUT = 7 days`, default `challengeTimeout = 600`.
- Chess limits: `MAX_PLY = 300` (per game), fifty-move rule at `halfmove >= 100`.
- Board encoding: square index `sq = rank * 8 + file` (a1 = 0, h1 = 7, a8 = 56, h8 = 63); 4 bits per square at bit offset `sq * 4`; piece codes `P=1 N=2 B=3 R=4 Q=5 K=6`, black adds 8 (`p=9 … k=14`), empty = 0.
- Meta encoding: bits 0–7 side to move (0 white, 1 black); 8–15 castling rights (`1=K, 2=Q, 4=k, 8=q`); 16–23 en-passant square (255 = none); 24–39 halfmove clock; 40–55 ply within the game; 56–63 status (`0 PLAYING, 1 DRAW_OFFERED, 2 WHITE_WON, 3 BLACK_WON, 4 DRAW`). All higher bits zero.
- Move encoding (`uint32`): bits 0–5 from, 6–11 to, 12–14 promotion piece type (0 or 2–5), 15–18 kind. All higher bits zero.
- Initial board `0xcabedbac99999999000000000000000000000000000000001111111142365324`; initial meta `0xFF0F00`.
- Player `participants[0]` (A) is white in even `gameIndex`, black in odd.
- Every commit message ends with the trailer line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Equivocation** — a mover who signed two different states for the same `turnNum` must never be able to replace a registered state with the other one (Task 10, `test_challenge_rejectsEquivocation`).
2. **Co-signed states that break conservation** — a state signed by both players whose `balanceA + balanceB != 2 * deposit` must revert, otherwise it drains other channels' escrow (Task 9, `test_closeCooperative_revertsWhenBalancesDontSum`).
3. **A payout recipient USDC refuses** (blocklisted) — the other party and the fee recipient are still paid; the blocked amount becomes claimable to another address (Task 9, `test_payout_deferredWhenRecipientBlocked_thenClaim`).
4. **Deadline boundary** — `respond` at exactly `deadline` reverts and `timeout` at exactly `deadline` succeeds, so there is no instant where both or neither work (Task 10, `test_deadlineBoundary`).
5. **Deposits into the wrong lifecycle** — deposit by a non-participant, a second deposit by the same participant, a deposit after `fundingDeadline`, and a deposit after `reclaim` all revert (Task 8).

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.28;

/// @notice Immutable per-channel parameters. A participant consents to them by calling ChannelHub.deposit.
struct Params {
    address[2] participants; // wallets: depositors and payout targets
    address[2] signers; // per-channel session keys that sign all states
    address rules; // IGameRules implementation
    address feeRecipient; // snapshot of hub config at channel creation
    uint256 feePerPlayer; // escrowed on top of `deposit`, never part of game balances
    uint256 deposit; // per-player game balance
    uint256 stakePerGame; // moved from loser to winner per decisive game
    uint64 challengeTimeout; // seconds
    uint64 fundingDeadline; // unix time
    bytes32 salt;
}

/// @notice A channel state. Signed with EIP-712 by session keys.
struct State {
    bytes32 channelId;
    uint64 turnNum;
    bytes32 prevHash;
    uint256 balanceA;
    uint256 balanceB;
    uint32 gameIndex;
    uint32 move;
    uint256 board;
    uint256 meta;
}

/// @notice A state with optional signatures by signers[0] (sigA) and signers[1] (sigB). Empty bytes = absent.
struct SignedState {
    State state;
    bytes sigA;
    bytes sigB;
}

/// @notice Evidence that `latest` is supported (spec §4.3). If `hasPrev` is false, `latest` must be the
/// opening state or signed by both signers. Otherwise `latest` is a move state following `prev`.
struct Proof {
    bool hasPrev;
    SignedState prev;
    SignedState latest;
}
```

`contracts/src/IGameRules.sol`:
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.28;

import {Params, State} from "./ArenaTypes.sol";

/// @notice A game template plugged into ChannelHub. Implementations must be deterministic and side-effect free.
interface IGameRules {
    /// @notice Opening state (turnNum 0) of a channel. It needs no signatures.
    function initialState(bytes32 channelId, Params calldata p) external view returns (State memory);

    /// @notice True if `s` is a checkpoint that must be signed by both players.
    function isCheckpoint(State calldata s) external view returns (bool);

    /// @notice Index (0 or 1) of the player whose session key signs the move state following `prev`.
    function mover(State calldata prev, Params calldata p) external view returns (uint8);

    /// @notice True if `next` legally follows `prev`. Ignores `prevHash`, which the hub checks.
    function validTransition(State calldata prev, State calldata next, Params calldata p)
        external
        view
        returns (bool);

    /// @notice True if no game is in progress in `s`; such a state settles with its balances as-is.
    function isGameOver(State calldata s) external view returns (bool);

    /// @notice Balances after the player on move in `s` forfeits the current game.
    function forfeitBalances(State calldata s, Params calldata p)
        external
        view
        returns (uint256 balanceA, uint256 balanceB);
}
```

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.28;

import {ChessBoard as B} from "../../src/chess/ChessBoard.sol";

/// @notice Helpers for writing chess positions and moves in tests using algebraic squares ("e4") and UCI ("e2e4", "a7a8q").
abstract contract ChessTestUtils {
    function sq(string memory s) internal pure returns (uint256) {
        bytes memory b = bytes(s);
        require(b.length == 2, "square must be like e4");
        return _sqAt(b, 0);
    }

    function place(uint256 board, string memory s, uint8 piece) internal pure returns (uint256) {
        return B.setPiece(board, sq(s), piece);
    }

    function uci(string memory m) internal pure returns (uint32) {
        return uciKind(m, B.KIND_NORMAL);
    }

    function uciKind(string memory m, uint8 kind) internal pure returns (uint32) {
        bytes memory b = bytes(m);
        require(b.length == 4 || b.length == 5, "uci must be like e2e4 or a7a8q");
        uint8 promo = 0;
        if (b.length == 5) {
            bytes1 c = b[4];
            if (c == "n") promo = B.KNIGHT;
            else if (c == "b") promo = B.BISHOP;
            else if (c == "r") promo = B.ROOK;
            else if (c == "q") promo = B.QUEEN;
            else revert("bad promotion piece");
        }
        return B.encodeMove(uint8(_sqAt(b, 0)), uint8(_sqAt(b, 2)), promo, kind);
    }

    function metaOf(uint8 side, uint8 castling, uint8 ep, uint16 halfmove, uint16 ply) internal pure returns (uint256) {
        return B.packMeta(side, castling, ep, halfmove, ply, B.STATUS_PLAYING);
    }

    function _sqAt(bytes memory b, uint256 i) private pure returns (uint256) {
        uint256 file = uint256(uint8(b[i])) - 97; // 'a'
        uint256 rank = uint256(uint8(b[i + 1])) - 49; // '1'
        require(file < 8 && rank < 8, "square out of range");
        return rank * 8 + file;
    }
}
```

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.28;

/// @notice Packed chess encoding shared by ChessMoves and ChessRules. See the plan's Global Constraints for layouts.
library ChessBoard {
    uint8 internal constant EMPTY = 0;
    uint8 internal constant PAWN = 1;
    uint8 internal constant KNIGHT = 2;
    uint8 internal constant BISHOP = 3;
    uint8 internal constant ROOK = 4;
    uint8 internal constant QUEEN = 5;
    uint8 internal constant KING = 6;
    uint8 internal constant BLACK = 8; // colour bit of a piece code

    uint8 internal constant WHITE_SIDE = 0;
    uint8 internal constant BLACK_SIDE = 1;

    uint8 internal constant CASTLE_WK = 1;
    uint8 internal constant CASTLE_WQ = 2;

        0xcabedbac99999999000000000000000000000000000000001111111142365324;

        return uint8((board >> (sq * 4)) & 0xF);
    }

    function setPiece(uint256 board, uint256 sq, uint8 piece) internal pure returns (uint256) {
        uint256 shift = sq * 4;
        return (board & ~(uint256(0xF) << shift)) | (uint256(piece) << shift);
    }

        return piece & 7;
    }

    function isBlack(uint8 piece) internal pure returns (bool) {
        return piece & BLACK != 0;
    }

        return uint8(meta & 0xFF);
    }

    function castling(uint256 meta) internal pure returns (uint8) {
        return uint8((meta >> 8) & 0xFF);
    }

    function epSquare(uint256 meta) internal pure returns (uint8) {
        return uint8((meta >> 16) & 0xFF);
    }

    function halfmove(uint256 meta) internal pure returns (uint16) {
        return uint16((meta >> 24) & 0xFFFF);
    }

    function ply(uint256 meta) internal pure returns (uint16) {
        return uint16((meta >> 40) & 0xFFFF);
    }

    function status(uint256 meta) internal pure returns (uint8) {
        return uint8((meta >> 56) & 0xFF);
    }

    function packMeta(uint8 side_, uint8 castling_, uint8 ep_, uint16 halfmove_, uint16 ply_, uint8 status_)
        internal
        pure
        returns (uint256)
    {
        return uint256(side_) | (uint256(castling_) << 8) | (uint256(ep_) << 16) | (uint256(halfmove_) << 24)
            | (uint256(ply_) << 40) | (uint256(status_) << 56);
    }

    function withStatus(uint256 meta, uint8 status_) internal pure returns (uint256) {
        return (meta & ~(uint256(0xFF) << 56)) | (uint256(status_) << 56);
    }

    function encodeMove(uint8 from, uint8 to, uint8 promo, uint8 kind) internal pure returns (uint32) {
        return uint32(from) | (uint32(to) << 6) | (uint32(promo) << 12) | (uint32(kind) << 15);
    }

    function moveFrom(uint32 m) internal pure returns (uint8) {
        return uint8(m & 63);
    }

    function moveTo(uint32 m) internal pure returns (uint8) {
        return uint8((m >> 6) & 63);
    }

    function movePromo(uint32 m) internal pure returns (uint8) {
        return uint8((m >> 12) & 7);
    }

    function moveKind(uint32 m) internal pure returns (uint8) {
        return uint8((m >> 15) & 15);
    }
```

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.28;

import {ChessBoard as B} from "./ChessBoard.sol";

/// @notice Chess legality over the packed encoding in ChessBoard. Mirrors chess.js 1.4.0 semantics.
library ChessMoves {
    /// @notice True if `sq` is attacked by any piece of the given colour.
    function isSquareAttacked(uint256 board, uint256 sq, bool byBlack) internal pure returns (bool) {
        int256 f = int256(sq % 8);
        int256 r = int256(sq / 8);
        uint8 color = byBlack ? B.BLACK : 0;

        // A white pawn attacks up the board, so it sits one rank below the square it attacks.
        int256 pr = byBlack ? r + 1 : r - 1;
        if (pr >= 0 && pr < 8) {
            if (f > 0 && B.pieceAt(board, _sq(f - 1, pr)) == (B.PAWN | color)) return true;
            if (f < 7 && B.pieceAt(board, _sq(f + 1, pr)) == (B.PAWN | color)) return true;
        }

        int8[8] memory kdf = [int8(1), 2, 2, 1, -1, -2, -2, -1];
        int8[8] memory kdr = [int8(2), 1, -1, -2, -2, -1, 1, 2];
        for (uint256 i = 0; i < 8; i++) {
            int256 nf = f + kdf[i];
            int256 nr = r + kdr[i];
            if (_onBoard(nf, nr) && B.pieceAt(board, _sq(nf, nr)) == (B.KNIGHT | color)) return true;
        }

        // Directions 0-3 are orthogonal, 4-7 diagonal. The first square of each ray also detects the king.
        int8[8] memory ddf = [int8(1), -1, 0, 0, 1, 1, -1, -1];
        int8[8] memory ddr = [int8(0), 0, 1, -1, 1, -1, 1, -1];
        for (uint256 d = 0; d < 8; d++) {
            int256 nf = f + ddf[d];
            int256 nr = r + ddr[d];
            bool first = true;
            while (_onBoard(nf, nr)) {
                uint8 p = B.pieceAt(board, _sq(nf, nr));
                if (p != 0) {
                    if ((p & B.BLACK) == color) {
                        uint8 t = p & 7;
                        if (t == B.QUEEN) return true;
                        if (d < 4 ? t == B.ROOK : t == B.BISHOP) return true;
                        if (first && t == B.KING) return true;
                    }
                    break;
                }
                first = false;
                nf += ddf[d];
                nr += ddr[d];
            }
        }
        return false;
    }

    /// @notice Square of the given colour's king, or 64 if there is none.
    function kingSquare(uint256 board, bool black) internal pure returns (uint256) {
        uint8 king = B.KING | (black ? B.BLACK : 0);
        for (uint256 s = 0; s < 64; s++) {
            if (B.pieceAt(board, s) == king) return s;
        }
        return 64;
    }

    /// @notice True if the side to move is in check.
    function inCheck(uint256 board, uint256 meta) internal pure returns (bool) {
        bool black = B.side(meta) == B.BLACK_SIDE;
        uint256 k = kingSquare(board, black);
        return k < 64 && isSquareAttacked(board, k, !black);
    }

    /// @notice Validates a move by the side to move and returns the resulting board and meta (status PLAYING).
    function applyMove(uint256 board, uint256 meta, uint256 from, uint256 to, uint8 promo)
        internal
        pure
        returns (bool ok, uint256 newBoard, uint256 newMeta)
    {
        if (from >= 64 || to >= 64 || from == to) return (false, 0, 0);
        bool black = B.side(meta) == B.BLACK_SIDE;
        uint8 piece = B.pieceAt(board, from);
        uint8 ptype = B.pieceType(piece);
        if (ptype == 0 || ptype > B.KING || B.isBlack(piece) != black) return (false, 0, 0);
        uint8 target = B.pieceAt(board, to);
        if (target != 0 && (B.isBlack(target) == black || B.pieceType(target) == B.KING)) return (false, 0, 0);

        uint8 ep = B.NO_EP;
        if (ptype == B.PAWN) {
            (ok, newBoard, ep) = _pawnMove(board, B.epSquare(meta), from, to, promo, black);
        } else if (promo != 0) {
            return (false, 0, 0);
        } else if (ptype == B.KING && from / 8 == to / 8 && (to + 2 == from || from + 2 == to)) {
            (ok, newBoard) = _castle(board, B.castling(meta), from, to, black);
        } else {
            ok = _pieceCanReach(board, ptype, from, to);
            newBoard = B.setPiece(B.setPiece(board, from, B.EMPTY), to, piece);
        }
        if (!ok) return (false, 0, 0);

        uint256 k = kingSquare(newBoard, black);
        if (k == 64 || isSquareAttacked(newBoard, k, !black)) return (false, 0, 0);

        uint8 rights = B.castling(meta);
        if (ptype == B.KING) rights &= black ? ~(B.CASTLE_BK | B.CASTLE_BQ) : ~(B.CASTLE_WK | B.CASTLE_WQ);
        rights = _dropRookRights(_dropRookRights(rights, from), to);
        uint16 hm = (ptype == B.PAWN || target != 0) ? uint16(0) : B.halfmove(meta) + 1;
        newMeta = B.packMeta(black ? B.WHITE_SIDE : B.BLACK_SIDE, rights, ep, hm, B.ply(meta) + 1, B.STATUS_PLAYING);
        return (true, newBoard, newMeta);
    }

    function _pieceCanReach(uint256 board, uint8 ptype, uint256 from, uint256 to) private pure returns (bool) {
        int256 df = int256(to % 8) - int256(from % 8);
        int256 dr = int256(to / 8) - int256(from / 8);
        uint256 adf = _abs(df);
        uint256 adr = _abs(dr);
        if (ptype == B.KNIGHT) return (adf == 1 && adr == 2) || (adf == 2 && adr == 1);
        if (ptype == B.KING) return adf <= 1 && adr <= 1;
        bool straight = df == 0 || dr == 0;
        bool diagonal = adf == adr;
        if (ptype == B.ROOK && !straight) return false;
        if (ptype == B.BISHOP && !diagonal) return false;
        if (ptype == B.QUEEN && !straight && !diagonal) return false;
        return _pathClear(board, from, df, dr);
    }

    function _pawnMove(uint256 board, uint8 epSq, uint256 from, uint256 to, uint8 promo, bool black)
        private
        pure
        returns (bool, uint256, uint8)
    {
        int256 df = int256(to % 8) - int256(from % 8);
        int256 dr = int256(to / 8) - int256(from / 8);
        int256 dir = black ? int256(-1) : int256(1);
        uint8 color = black ? B.BLACK : 0;
        uint8 target = B.pieceAt(board, to);
        uint256 nb = B.setPiece(board, from, B.EMPTY);
        uint8 ep = B.NO_EP;

        if (df == 0) {
            if (target != 0) return (false, 0, 0);
            if (dr == 2 * dir) {
                if (from / 8 != (black ? 6 : 1)) return (false, 0, 0);
                uint256 mid = black ? from - 8 : from + 8;
                if (B.pieceAt(board, mid) != 0) return (false, 0, 0);
                ep = uint8(mid);
            } else if (dr != dir) {
                return (false, 0, 0);
            }
        } else if ((df == 1 || df == -1) && dr == dir) {
            if (target == 0) {
                if (to != epSq) return (false, 0, 0);
                uint256 captured = black ? to + 8 : to - 8;
                if (B.pieceAt(board, captured) != (B.PAWN | (black ? 0 : B.BLACK))) return (false, 0, 0);
                nb = B.setPiece(nb, captured, B.EMPTY);
            }
        } else {
            return (false, 0, 0);
        }

        uint8 placed = B.PAWN | color;
        if (to / 8 == (black ? 0 : 7)) {
            if (promo < B.KNIGHT || promo > B.QUEEN) return (false, 0, 0);
            placed = promo | color;
        } else if (promo != 0) {
            return (false, 0, 0);
        }
        return (true, B.setPiece(nb, to, placed), ep);
    }

    function _castle(uint256 board, uint8 rights, uint256 from, uint256 to, bool black)
        private
        pure
        returns (bool, uint256)
    {
        uint256 home = black ? 60 : 4;
        if (from != home) return (false, 0);
        bool kingSide = to == home + 2;
        uint8 right = black ? (kingSide ? B.CASTLE_BK : B.CASTLE_BQ) : (kingSide ? B.CASTLE_WK : B.CASTLE_WQ);
        if ((rights & right) == 0) return (false, 0);
        uint8 color = black ? B.BLACK : 0;
        uint256 rookFrom = kingSide ? home + 3 : home - 4;
        uint256 rookTo = kingSide ? home + 1 : home - 1;
        if (B.pieceAt(board, rookFrom) != (B.ROOK | color)) return (false, 0);
        if (B.pieceAt(board, rookTo) != 0 || B.pieceAt(board, to) != 0) return (false, 0);
        if (!kingSide && B.pieceAt(board, home - 3) != 0) return (false, 0);
        // Not out of check, not through an attacked square; the destination is checked by the caller.
        if (isSquareAttacked(board, home, !black) || isSquareAttacked(board, rookTo, !black)) return (false, 0);
        uint256 nb = B.setPiece(B.setPiece(board, home, B.EMPTY), rookFrom, B.EMPTY);
        nb = B.setPiece(B.setPiece(nb, to, B.KING | color), rookTo, B.ROOK | color);
        return (true, nb);
    }

    function _dropRookRights(uint8 rights, uint256 s) private pure returns (uint8) {
        if (s == 0) return rights & ~B.CASTLE_WQ;
        if (s == 7) return rights & ~B.CASTLE_WK;
        if (s == 56) return rights & ~B.CASTLE_BQ;
        if (s == 63) return rights & ~B.CASTLE_BK;
        return rights;
    }

    function _pathClear(uint256 board, uint256 from, int256 df, int256 dr) private pure returns (bool) {
        int256 sf = df > 0 ? int256(1) : (df < 0 ? int256(-1) : int256(0));
        int256 sr = dr > 0 ? int256(1) : (dr < 0 ? int256(-1) : int256(0));
        uint256 n = _abs(df) > _abs(dr) ? _abs(df) : _abs(dr);
        int256 f = int256(from % 8);
        int256 r = int256(from / 8);
```

```solidity
    /// @notice True if the side to move has at least one legal move. Used only for stalemate/mate proofs.
    function hasLegalMove(uint256 board, uint256 meta) internal pure returns (bool) {
        bool black = B.side(meta) == B.BLACK_SIDE;
        for (uint256 from = 0; from < 64; from++) {
            uint8 piece = B.pieceAt(board, from);
            if (piece == 0 || B.isBlack(piece) != black) continue;
            if (_pieceHasMove(board, meta, from, B.pieceType(piece), black)) return true;
        }
        return false;
    }

    /// @notice Mirrors chess.js isInsufficientMaterial(): K v K, K+minor v K, or only same-coloured bishops.
    function isInsufficientMaterial(uint256 board) internal pure returns (bool) {
        uint256 pieces;
        uint256 bishops;
        uint256 knights;
        uint256 bishopsOnEvenSquares;
        for (uint256 s = 0; s < 64; s++) {
            uint8 p = B.pieceAt(board, s);
            if (p == 0) continue;
            pieces++;
            uint8 t = p & 7;
            if (t == B.BISHOP) {
                bishops++;
                if ((s % 8 + s / 8) % 2 == 0) bishopsOnEvenSquares++;
            } else if (t == B.KNIGHT) {
                knights++;
            }
        }
        if (pieces == 2) return true;
        if (pieces == 3 && (bishops == 1 || knights == 1)) return true;
        if (pieces == bishops + 2 && (bishopsOnEvenSquares == 0 || bishopsOnEvenSquares == bishops)) return true;
        return false;
    }
```

```ts
// FEN → the packed (board, meta) encoding defined in the contracts plan's Global Constraints.
export const PIECE: Record<string, number> = {
  P: 1, N: 2, B: 3, R: 4, Q: 5, K: 6,
  p: 9, n: 10, b: 11, r: 12, q: 13, k: 14,
};

export const PROMO: Record<string, number> = { n: 2, b: 3, r: 4, q: 5 };

export const INITIAL_BOARD = 0xcabedbac99999999000000000000000000000000000000001111111142365324n;
export const INITIAL_META = 0xff0f00n;

export function squareIndex(sq: string): number {
  return sq.charCodeAt(0) - 97 + (sq.charCodeAt(1) - 49) * 8;
}

export function encodeFen(fen: string): { board: bigint; meta: bigint } {
  const [placement, side, castling, ep, half, full] = fen.split(" ");
  let board = 0n;
  placement.split("/").forEach((row, i) => {
    const rank = 7 - i;
    let file = 0;
    for (const ch of row) {
      if (ch >= "1" && ch <= "8") {
        file += Number(ch);
      } else {
        board |= BigInt(PIECE[ch]) << BigInt((rank * 8 + file) * 4);
        file++;
      }
    }
  });
  let rights = 0;
  if (castling.includes("K")) rights |= 1;
  if (castling.includes("Q")) rights |= 2;
  if (castling.includes("k")) rights |= 4;
  if (castling.includes("q")) rights |= 8;
  const sideN = side === "w" ? 0 : 1;
  const epSq = ep === "-" ? 255 : squareIndex(ep);
  const ply = (Number(full) - 1) * 2 + sideN;
  const meta =
    BigInt(sideN) |
    (BigInt(rights) << 8n) |
    (BigInt(epSq) << 16n) |
    (BigInt(Number(half)) << 24n) |
    (BigInt(ply) << 40n);
  return { board, meta };
}
```

```ts
  const turnIsWhite = game.turn() === "w";
  for (let s = 0; s < 64; s++) {
    const piece = Number((board >> BigInt(s * 4)) & 0xfn);
    if (piece !== 0 && (piece & 8) === (turnIsWhite ? 0 : 8)) ownSquares.push(s);
  }
  let guard = 0;
  while (illegal.length < ILLEGAL_PER_POSITION && guard++ < 2000) {
    const from = rand() < 0.8 && ownSquares.length > 0 ? ownSquares[Math.floor(rand() * ownSquares.length)] : Math.floor(rand() * 64);
    const to = Math.floor(rand() * 64);
    const promo = rand() < 0.1 ? 2 + Math.floor(rand() * 4) : 0;
    if (!legalKeys.has(key(from, to, promo))) illegal.push({ from, to, promo });
  }
  return {
    fen,
    board,
    meta,
    inCheck: game.inCheck(),
    hasLegalMove: moves.length > 0,
    insufficient: game.isInsufficientMaterial(),
    legal,
    illegal,
  };
}

function main() {
  const rand = mulberry32(SEED);
  const fens = [...CURATED_FENS];
  for (let g = 0; g < GAMES; g++) fens.push(...sample(randomGameFens(rand), rand));
  const chunks: ReturnType<typeof positionCase>[][] = Array.from({ length: CHUNKS }, () => []);
  fens.forEach((fen, i) => chunks[i % CHUNKS].push(positionCase(fen, rand)));
  mkdirSync(OUT_DIR, { recursive: true });
  let moves = 0;
  chunks.forEach((cases, i) => {
    moves += cases.reduce((n, c) => n + c.legal.length + c.illegal.length, 0);
    writeFileSync(resolve(OUT_DIR, `chunk-${i}.hex`), encodeAbiParameters(CASES_ABI, [cases]));
  });
  console.log(`wrote ${fens.length} positions, ${moves} move checks, ${CHUNKS} chunks to ${OUT_DIR}`);
}
```

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.28;

import {IGameRules} from "../IGameRules.sol";
import {Params, State} from "../ArenaTypes.sol";
import {ChessBoard as B} from "./ChessBoard.sol";
import {ChessMoves} from "./ChessMoves.sol";

/// @notice Chess template for ChannelHub. Checkmate is not detected on-chain: a mated player cannot respond
/// to a challenge with a legal move and forfeits on timeout (spec §4.5).
contract ChessRules is IGameRules {
    uint16 public constant MAX_PLY = 300;
    uint16 public constant FIFTY_MOVE_HALFMOVES = 100;

    function initialState(bytes32 channelId, Params calldata p) external pure returns (State memory s) {
        s.channelId = channelId;
        s.balanceA = p.deposit;
        s.balanceB = p.deposit;
        s.board = B.INITIAL_BOARD;
        s.meta = B.INITIAL_META;
    }

    function isCheckpoint(State calldata s) external pure returns (bool) {
        return B.moveKind(s.move) == B.KIND_NEW_GAME;
    }

    function isGameOver(State calldata s) external pure returns (bool) {
        uint8 st = B.status(s.meta);
        return st == B.STATUS_WHITE_WON || st == B.STATUS_BLACK_WON || st == B.STATUS_DRAW;
    }

    function mover(State calldata prev, Params calldata) external pure returns (uint8) {
        return _playerOnMove(prev.gameIndex, prev.meta);
    }

    function forfeitBalances(State calldata s, Params calldata p) external pure returns (uint256, uint256) {
        return _shiftStake(s.balanceA, s.balanceB, _playerOnMove(s.gameIndex, s.meta), p.stakePerGame);
    }

    function validTransition(State calldata prev, State calldata next, Params calldata p)
        external
        pure
        returns (bool)
    {
        (bool ok, State memory e) = successor(prev, next.move, p);
        return ok && e.channelId == next.channelId && e.turnNum == next.turnNum && e.balanceA == next.balanceA
            && e.balanceB == next.balanceB && e.gameIndex == next.gameIndex && e.board == next.board
            && e.meta == next.meta;
    }

    /// @notice The canonical state after applying `move` to `prev`. `prevHash` is left zero (the hub owns it).
    function successor(State calldata prev, uint32 move, Params calldata p)
        public
        pure
        returns (bool ok, State memory next)
    {
        next = prev;
        next.turnNum = prev.turnNum + 1;
        next.prevHash = bytes32(0);
        next.move = move;
        uint8 kind = B.moveKind(move);
        uint8 st = B.status(prev.meta);
        bool inProgress = st == B.STATUS_PLAYING || st == B.STATUS_DRAW_OFFERED;

        if (kind == B.KIND_NEW_GAME) {
            if (inProgress || move != B.encodeMove(0, 0, 0, B.KIND_NEW_GAME)) return (false, next);
            if (prev.balanceA < p.stakePerGame || prev.balanceB < p.stakePerGame) return (false, next);
            next.gameIndex = prev.gameIndex + 1;
            next.board = B.INITIAL_BOARD;
            next.meta = B.INITIAL_META;
            return (true, next);
        }
        if (!inProgress) return (false, next);

        if (kind == B.KIND_NORMAL || kind == B.KIND_NORMAL_OFFER_DRAW) {
            return _normalMove(prev, move, kind, p, next);
        }
        if (move != B.encodeMove(0, 0, 0, kind)) return (false, next);
        if (kind == B.KIND_RESIGN) {
            bool whiteResigns = B.side(prev.meta) == B.WHITE_SIDE;
            next.meta = B.withStatus(prev.meta, whiteResigns ? B.STATUS_BLACK_WON : B.STATUS_WHITE_WON);
            (next.balanceA, next.balanceB) = _shiftStake(
                prev.balanceA, prev.balanceB, _playerOnMove(prev.gameIndex, prev.meta), p.stakePerGame
            );
            return (true, next);
        }
        if (kind == B.KIND_ACCEPT_DRAW) {
            if (st != B.STATUS_DRAW_OFFERED) return (false, next);
            next.meta = B.withStatus(prev.meta, B.STATUS_DRAW);
            return (true, next);
        }
        if (kind == B.KIND_CLAIM_STALEMATE) {
            if (ChessMoves.inCheck(prev.board, prev.meta) || ChessMoves.hasLegalMove(prev.board, prev.meta)) {
                return (false, next);
            }
            next.meta = B.withStatus(prev.meta, B.STATUS_DRAW);
            return (true, next);
        }
        return (false, next);
    }

    function _normalMove(State calldata prev, uint32 move, uint8 kind, Params calldata p, State memory next)
        private
        pure
        returns (bool, State memory)
    {
        uint8 from = B.moveFrom(move);
        uint8 to = B.moveTo(move);
        uint8 promo = B.movePromo(move);
        if (move != B.encodeMove(from, to, promo, kind)) return (false, next);
        (bool legal, uint256 board, uint256 meta) = ChessMoves.applyMove(prev.board, prev.meta, from, to, promo);
        if (!legal) return (false, next);

        uint8 status = kind == B.KIND_NORMAL_OFFER_DRAW ? B.STATUS_DRAW_OFFERED : B.STATUS_PLAYING;
        if (ChessMoves.isInsufficientMaterial(board)) {
            status = B.STATUS_DRAW;
        } else if (B.halfmove(meta) >= FIFTY_MOVE_HALFMOVES || B.ply(meta) >= MAX_PLY) {
            // A checkmate delivered by the limiting move still wins; otherwise the game is drawn.
            if (ChessMoves.inCheck(board, meta) && !ChessMoves.hasLegalMove(board, meta)) {
                status = B.side(prev.meta) == B.WHITE_SIDE ? B.STATUS_WHITE_WON : B.STATUS_BLACK_WON;
                (next.balanceA, next.balanceB) = _shiftStake(
                    prev.balanceA, prev.balanceB, _playerOnMove(prev.gameIndex, meta), p.stakePerGame
                );
            } else {
                status = B.STATUS_DRAW;
            }
        }
        next.board = board;
        next.meta = B.withStatus(meta, status);
        return (true, next);
    }

    function _playerOnMove(uint32 gameIndex, uint256 meta) private pure returns (uint8) {
        uint8 whitePlayer = uint8(gameIndex % 2);
        return B.side(meta) == B.WHITE_SIDE ? whitePlayer : 1 - whitePlayer;
    }

    function _shiftStake(uint256 a, uint256 b, uint8 loser, uint256 stake) private pure returns (uint256, uint256) {
        if (loser == 0) {
            uint256 x = stake < a ? stake : a;
            return (a - x, b + x);
        }
        uint256 y = stake < b ? stake : b;
        return (a + y, b - y);
    }
}
```

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.28;

import {IERC20} from "@openzeppelin/contracts/token/ERC20/IERC20.sol";
import {SafeERC20} from "@openzeppelin/contracts/token/ERC20/utils/SafeERC20.sol";
import {EIP712} from "@openzeppelin/contracts/utils/cryptography/EIP712.sol";
import {SignatureChecker} from "@openzeppelin/contracts/utils/cryptography/SignatureChecker.sol";
import {Ownable} from "@openzeppelin/contracts/access/Ownable.sol";
import {Ownable2Step} from "@openzeppelin/contracts/access/Ownable2Step.sol";
import {ReentrancyGuard} from "@openzeppelin/contracts/utils/ReentrancyGuard.sol";
import {Params, State, SignedState, Proof} from "./ArenaTypes.sol";
import {IGameRules} from "./IGameRules.sol";

/// @notice Two-party state-channel adjudicator with force-move disputes (spec §4.6). Non-upgradeable.
contract ChannelHub is EIP712, Ownable2Step, ReentrancyGuard {
    using SafeERC20 for IERC20;

    enum Phase {
        None,
        Funding,
        Open,
        Challenged,
        Finalized,
        Reclaimed
    }

    struct Channel {
        Phase phase;
        bool[2] funded;
        bool hasRegistered;
        uint8 challenger;
        uint64 deadline;
        uint64[2] cooldownUntil;
        bytes32 registeredHash;
        State registered;
        Params params;
    }

    struct ChannelInfo {
        Phase phase;
        bool[2] funded;
        bool hasRegistered;
        uint8 challenger;
        uint64 deadline;
        uint64[2] cooldownUntil;
        bytes32 registeredHash;
    }

    bytes32 public constant STATE_TYPEHASH = keccak256(
        "State(bytes32 channelId,uint64 turnNum,bytes32 prevHash,uint256 balanceA,uint256 balanceB,uint32 gameIndex,uint32 move,uint256 board,uint256 meta)"
    );
    uint64 public constant MIN_TIMEOUT = 60;
    uint64 public constant MAX_TIMEOUT = 7 days;

    IERC20 public immutable token;
    uint256 public immutable maxFeePerPlayer;
    uint256 public feePerPlayer;
    address public feeRecipient;
    mapping(address => uint256) public owed;
    mapping(bytes32 => Channel) internal _channels;

    event ChannelCreated(bytes32 indexed channelId, bytes params);
    event Deposited(bytes32 indexed channelId, uint8 indexed player, uint256 amount);
    event Opened(bytes32 indexed channelId);
    event Challenged(bytes32 indexed channelId, uint8 indexed challenger, uint64 turnNum, uint64 deadline, bytes signedState);
    event Responded(bytes32 indexed channelId, uint64 turnNum, bytes signedState);
    event Finalized(bytes32 indexed channelId, uint256 balanceA, uint256 balanceB, uint256 fee);
    event Reclaimed(bytes32 indexed channelId);
    event PayoutDeferred(address indexed to, uint256 amount);
    event Claimed(address indexed from, address indexed to, uint256 amount);
    event FeeUpdated(uint256 feePerPlayer, address feeRecipient);

    error WrongPhase();
    error InvalidParams();
    error FeeMismatch();
    error FundingClosed();
    error NotParticipant();
    error AlreadyFunded();
    error TooEarly();
    error DeadlinePassed();
    error BadSignature();
    error Unsupported();
    error InvalidTransition();
    error StaleState();
    error NotClosable();
    error BalanceMismatch();
    error InCooldown();
    error NothingToClaim();

    constructor(IERC20 token_, address owner_, address feeRecipient_, uint256 feePerPlayer_, uint256 maxFeePerPlayer_)
        EIP712("AgentArena", "1")
        Ownable(owner_)
    {
        if (address(token_).code.length == 0) revert InvalidParams();
        token = token_;
        maxFeePerPlayer = maxFeePerPlayer_;
        _setFee(feePerPlayer_, feeRecipient_);
    }

    // ----------------------------------------------------------------- views

    function channelId(Params memory p) public view returns (bytes32) {
        return keccak256(abi.encode(block.chainid, address(this), p));
    }

    function hashState(State memory s) public view returns (bytes32) {
        return _hashTypedDataV4(
            keccak256(
                abi.encode(
                    STATE_TYPEHASH,
                    s.channelId,
                    s.turnNum,
                    s.prevHash,
                    s.balanceA,
                    s.balanceB,
                    s.gameIndex,
                    s.move,
                    s.board,
                    s.meta
                )
            )
        );
    }

    function channelInfo(bytes32 id) external view returns (ChannelInfo memory info) {
        Channel storage c = _channels[id];
        info = ChannelInfo(
            c.phase, c.funded, c.hasRegistered, c.challenger, c.deadline, c.cooldownUntil, c.registeredHash
        );
    }

    function channelParams(bytes32 id) external view returns (Params memory) {
        return _channels[id].params;
    }

    function registeredState(bytes32 id) external view returns (State memory) {
        return _channels[id].registered;
    }

    // --------------------------------------------------------------- funding

    /// @notice Fund your side of a channel. Calling this is the participant's consent to every field of `params`.
    function deposit(bytes calldata encodedParams) external nonReentrant {
        Params memory p = abi.decode(encodedParams, (Params));
        bytes32 id = channelId(p);
        Channel storage c = _channels[id];
        if (c.phase == Phase.None) {
            _validateNewParams(p);
            c.phase = Phase.Funding;
            c.params = p;
            emit ChannelCreated(id, encodedParams);
        } else if (c.phase != Phase.Funding) {
            revert WrongPhase();
        }
        if (block.timestamp > p.fundingDeadline) revert FundingClosed();
        uint8 i = _participantIndex(p, msg.sender);
        if (c.funded[i]) revert AlreadyFunded();
        c.funded[i] = true;
        uint256 amount = p.deposit + p.feePerPlayer;
        emit Deposited(id, i, amount);
        if (c.funded[0] && c.funded[1]) {
            c.phase = Phase.Open;
            emit Opened(id);
        }
        token.safeTransferFrom(msg.sender, address(this), amount);
    }

    /// @notice Refund a channel that never fully funded. Anyone may call after the funding deadline.
    function reclaim(bytes32 id) external nonReentrant {
        Channel storage c = _channels[id];
        if (c.phase != Phase.Funding) revert WrongPhase();
        Params memory p = c.params;
        if (block.timestamp <= p.fundingDeadline) revert TooEarly();
        c.phase = Phase.Reclaimed;
        emit Reclaimed(id);
        uint256 amount = p.deposit + p.feePerPlayer;
        if (c.funded[0]) _pay(p.participants[0], amount);
        if (c.funded[1]) _pay(p.participants[1], amount);
    }

    /// @notice Withdraw payouts that could not be pushed (e.g. the recipient was blocked by the token).
    function claim(address to) external nonReentrant {
        uint256 amount = owed[msg.sender];
        if (amount == 0) revert NothingToClaim();
        owed[msg.sender] = 0;
        emit Claimed(msg.sender, to, amount);
        token.safeTransfer(to, amount);
    }

    // ----------------------------------------------------------------- admin

    /// @notice Set the fee for channels created from now on. Existing channels keep their snapshot.
    function setFee(uint256 feePerPlayer_, address feeRecipient_) external onlyOwner {
        _setFee(feePerPlayer_, feeRecipient_);
    }

    // -------------------------------------------------------------- internal

    function _setFee(uint256 feePerPlayer_, address feeRecipient_) private {
        if (feePerPlayer_ > maxFeePerPlayer || feeRecipient_ == address(0)) revert InvalidParams();
        feePerPlayer = feePerPlayer_;
        feeRecipient = feeRecipient_;
        emit FeeUpdated(feePerPlayer_, feeRecipient_);
    }

    function _validateNewParams(Params memory p) private view {
        if (
            p.participants[0] == address(0) || p.participants[1] == address(0)
                || p.participants[0] == p.participants[1] || p.signers[0] == address(0) || p.signers[1] == address(0)
                || p.signers[0] == p.signers[1] || p.rules.code.length == 0 || p.stakePerGame == 0
                || p.deposit < p.stakePerGame || p.fundingDeadline <= block.timestamp
                || p.challengeTimeout < MIN_TIMEOUT || p.challengeTimeout > MAX_TIMEOUT
        ) revert InvalidParams();
        if (p.feePerPlayer < feePerPlayer || p.feeRecipient != feeRecipient) revert FeeMismatch();
    }

    function _participantIndex(Params memory p, address who) private pure returns (uint8) {
        if (who == p.participants[0]) return 0;
        if (who == p.participants[1]) return 1;
        revert NotParticipant();
    }

    /// @dev Push a payout; if the token refuses (blocklist, paused), credit it to `owed` instead of reverting,
    /// so one blocked recipient can never lock the other party's funds.
    function _pay(address to, uint256 amount) private {
        if (amount == 0) return;
        (bool ok, bytes memory ret) = address(token).call(abi.encodeCall(IERC20.transfer, (to, amount)));
        if (ok && (ret.length == 0 || abi.decode(ret, (bool)))) return;
        owed[to] += amount;
        emit PayoutDeferred(to, amount);
    }
}
```

```solidity
    /// @notice Settle immediately on a state signed by both players: the opening state, a NEW_GAME checkpoint,
    /// or a finished game. Game results are already applied to balances in such states.
    function closeCooperative(bytes calldata encodedSignedState) external nonReentrant {
        SignedState memory ss = abi.decode(encodedSignedState, (SignedState));
        State memory s = ss.state;
        bytes32 id = s.channelId;
        Channel storage c = _channels[id];
        if (c.phase != Phase.Open && c.phase != Phase.Challenged) revert WrongPhase();
        Params memory p = c.params;
        _checkBalances(p, s);
        bytes32 h = hashState(s);
        if (!_signedBy(p.signers[0], h, ss.sigA) || !_signedBy(p.signers[1], h, ss.sigB)) revert BadSignature();
        IGameRules rules = IGameRules(p.rules);
        if (s.turnNum != 0 && !rules.isCheckpoint(s) && !rules.isGameOver(s)) revert NotClosable();
        if (c.hasRegistered && s.turnNum < c.registered.turnNum) revert StaleState();
        _finalize(id, c, p, s.balanceA, s.balanceB);
```

```solidity
    /// @notice Register a supported state on-chain and start the clock for the player on move.
    /// Callable by either player's wallet or session key. A state with the same turnNum as the registered
    /// one is accepted only if it is identical, which lets the waiting player challenge after a response.
    function challenge(bytes calldata encodedProof) external nonReentrant {
        Proof memory proof = abi.decode(encodedProof, (Proof));
        bytes32 id = proof.latest.state.channelId;
        Channel storage c = _channels[id];
        if (c.phase != Phase.Open) revert WrongPhase();
        Params memory p = c.params;
        uint8 who = _playerIndex(p, msg.sender);
        if (block.timestamp < c.cooldownUntil[who]) revert InCooldown();
        (State memory s, bytes32 h) = _supported(c, p, id, proof);
        if (c.hasRegistered) {
            uint64 reg = c.registered.turnNum;
            if (s.turnNum < reg || (s.turnNum == reg && h != c.registeredHash)) revert StaleState();
        }
        _register(c, s, h);
        c.challenger = who;
        c.deadline = uint64(block.timestamp) + p.challengeTimeout;
        c.phase = Phase.Challenged;
        emit Challenged(id, who, s.turnNum, c.deadline, abi.encode(proof.latest));
    }

    /// @notice Answer a challenge with any supported newer state. Returns the channel to off-chain play and
    /// puts the challenger in cooldown for one challengeTimeout.
    function respond(bytes calldata encodedProof) external nonReentrant {
        Proof memory proof = abi.decode(encodedProof, (Proof));
        bytes32 id = proof.latest.state.channelId;
        Channel storage c = _channels[id];
        if (c.phase != Phase.Challenged) revert WrongPhase();
        if (block.timestamp >= c.deadline) revert DeadlinePassed();
        Params memory p = c.params;
        (State memory s, bytes32 h) = _supported(c, p, id, proof);
        if (s.turnNum <= c.registered.turnNum) revert StaleState();
        _register(c, s, h);
        c.cooldownUntil[c.challenger] = uint64(block.timestamp) + p.challengeTimeout;
        c.phase = Phase.Open;
        emit Responded(id, s.turnNum, abi.encode(proof.latest));
    }

    /// @notice After an unanswered challenge: the player on move forfeits the current game, or a finished
    /// game settles as-is. Anyone may call.
    function timeout(bytes32 id) external nonReentrant {
        Channel storage c = _channels[id];
        if (c.phase != Phase.Challenged) revert WrongPhase();
        if (block.timestamp < c.deadline) revert TooEarly();
        State memory s = c.registered;
        Params memory p = c.params;
        IGameRules rules = IGameRules(p.rules);
        uint256 a = s.balanceA;
        uint256 b = s.balanceB;
        if (!rules.isGameOver(s)) (a, b) = rules.forfeitBalances(s, p);
        _finalize(id, c, p, a, b);
    }
```

```solidity
    /// @dev Spec §4.3 support rule. Returns the supported latest state and its EIP-712 hash.
    function _supported(Channel storage c, Params memory p, bytes32 id, Proof memory proof)
        private
        view
        returns (State memory s, bytes32 h)
    {
        s = proof.latest.state;
        _checkBalances(p, s);
        h = hashState(s);
        IGameRules rules = IGameRules(p.rules);
        if (!proof.hasPrev) {
            if (s.turnNum == 0 && _isOpening(rules, id, p, h)) return (s, h);
            if (_signedBy(p.signers[0], h, proof.latest.sigA) && _signedBy(p.signers[1], h, proof.latest.sigB)) {
                return (s, h);
            }
            revert Unsupported();
        }

        State memory prev = proof.prev.state;
        if (prev.channelId != id || rules.isCheckpoint(s)) revert Unsupported();
        bytes32 ph = hashState(prev);
        if (s.prevHash != ph || s.turnNum != prev.turnNum + 1) revert Unsupported();
        uint8 m = rules.mover(prev, p);
        if (!_signedBy(p.signers[m], h, m == 0 ? proof.latest.sigA : proof.latest.sigB)) revert BadSignature();
        if (!rules.validTransition(prev, s, p)) revert InvalidTransition();

        bool prevEndorsed = (c.hasRegistered && ph == c.registeredHash)
            || (prev.turnNum == 0 && _isOpening(rules, id, p, ph))
            || (_signedBy(p.signers[0], ph, proof.prev.sigA) && _signedBy(p.signers[1], ph, proof.prev.sigB))
            || _signedBy(p.signers[1 - m], ph, m == 0 ? proof.prev.sigB : proof.prev.sigA);
        if (!prevEndorsed) revert Unsupported();
    }

    function _isOpening(IGameRules rules, bytes32 id, Params memory p, bytes32 h) private view returns (bool) {
        return h == hashState(rules.initialState(id, p));
    }

    function _register(Channel storage c, State memory s, bytes32 h) private {
        c.registered = s;
        c.registeredHash = h;
        c.hasRegistered = true;
    }

    function _playerIndex(Params memory p, address who) private pure returns (uint8) {
        if (who == p.participants[0] || who == p.signers[0]) return 0;
        if (who == p.participants[1] || who == p.signers[1]) return 1;
        revert NotParticipant();
    }
```

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.28;

import {Test} from "forge-std/Test.sol";
import {Params, State, SignedState, Proof} from "../../src/ArenaTypes.sol";
import {ChannelHub} from "../../src/ChannelHub.sol";
import {ChessRules} from "../../src/chess/ChessRules.sol";

/// @notice Drives random channel lifecycles and tracks how much USDC the hub should hold.
contract HubHandler is Test {
    ChannelHub internal hub;
    ChessRules internal rules;
    address internal alice;
    address internal bob;
    address internal aliceSigner;
    address internal bobSigner;
    uint256 internal aliceKey;
    uint256 internal bobKey;
    address internal feeRecipient;

    Params[] internal channels;
    uint256 public ghostEscrow;
    uint256 internal nonce;

    constructor(
        ChannelHub hub_,
        ChessRules rules_,
        address[2] memory players,
        address[2] memory signers,
        uint256[2] memory keys,
        address feeRecipient_
    ) {
        hub = hub_;
        rules = rules_;
        (alice, bob) = (players[0], players[1]);
        (aliceSigner, bobSigner) = (signers[0], signers[1]);
        (aliceKey, bobKey) = (keys[0], keys[1]);
        feeRecipient = feeRecipient_;
    }

    function create(uint256 depositSeed) external {
        Params memory p;
        p.participants = [alice, bob];
        p.signers = [aliceSigner, bobSigner];
        p.rules = address(rules);
        p.feeRecipient = feeRecipient;
        p.feePerPlayer = hub.feePerPlayer();
        p.stakePerGame = 100_000;
        p.deposit = bound(depositSeed, 100_000, 5_000_000);
        p.challengeTimeout = 600;
        p.fundingDeadline = uint64(block.timestamp + 1 hours);
        p.salt = keccak256(abi.encode(nonce++));
        vm.prank(alice);
        hub.deposit(abi.encode(p));
        ghostEscrow += p.deposit + p.feePerPlayer;
        channels.push(p);
    }

    function fund(uint256 idx) external {
        (bool found, Params memory p) = _pick(idx, ChannelHub.Phase.Funding);
        if (!found || block.timestamp > p.fundingDeadline) return;
        vm.prank(bob);
        hub.deposit(abi.encode(p));
        ghostEscrow += p.deposit + p.feePerPlayer;
    }

    function reclaim(uint256 idx) external {
        (bool found, Params memory p) = _pick(idx, ChannelHub.Phase.Funding);
        if (!found) return;
        if (block.timestamp <= p.fundingDeadline) vm.warp(p.fundingDeadline + 1);
        hub.reclaim(hub.channelId(p));
        ghostEscrow -= p.deposit + p.feePerPlayer; // only alice funded while in Funding
    }

    function closeOpening(uint256 idx) external {
        (bool found, Params memory p) = _pick(idx, ChannelHub.Phase.Open);
        if (!found) return;
        State memory s = rules.initialState(hub.channelId(p), p);
        SignedState memory ss;
        ss.state = s;
        ss.sigA = _sign(aliceKey, s);
        ss.sigB = _sign(bobKey, s);
        hub.closeCooperative(abi.encode(ss));
        ghostEscrow -= 2 * (p.deposit + p.feePerPlayer);
    }

    function challengeAndTimeout(uint256 idx) external {
        (bool found, Params memory p) = _pick(idx, ChannelHub.Phase.Open);
        if (!found) return;
        bytes32 id = hub.channelId(p);
        if (block.timestamp < hub.channelInfo(id).cooldownUntil[1]) return;
        Proof memory pr;
        pr.latest.state = rules.initialState(id, p);
        vm.prank(bob);
        hub.challenge(abi.encode(pr));
        vm.warp(block.timestamp + p.challengeTimeout);
        hub.timeout(id);
        ghostEscrow -= 2 * (p.deposit + p.feePerPlayer);
    }

    function _pick(uint256 idx, ChannelHub.Phase phase) internal view returns (bool, Params memory) {
        uint256 n = channels.length;
        for (uint256 k = 0; k < n; k++) {
            Params memory p = channels[(idx % n + k) % n];
            if (hub.channelInfo(hub.channelId(p)).phase == phase) return (true, p);
        }
        Params memory none;
        return (false, none);
    }

    function _sign(uint256 key, State memory s) internal view returns (bytes memory) {
        (uint8 v, bytes32 r, bytes32 sg) = vm.sign(key, hub.hashState(s));
        return abi.encodePacked(r, sg, v);
    }
}
```

```markdown
# Arena contracts

On-chain half of the Agent Chess Arena (spec: `docs/superpowers/specs/2026-09-24-agent-chess-arena-design.md`).

- `ChannelHub` — escrow, EIP-712 signature checks (ECDSA + ERC-1271), force-move disputes, fee payout.
- `IGameRules` — game template interface. `ChessRules` — chess template.
- `ChessBoard` / `ChessMoves` — packed encoding and legality (see the encodings below).

## Commands

    pnpm vectors                 # generate chess.js differential vectors (needed by forge test)
    pnpm test:contracts          # vectors + full forge test suite
    forge script script/Deploy.s.sol --rpc-url <rpc> --broadcast --private-key <key>

Deploy env: `ARENA_OWNER`, `ARENA_FEE_RECIPIENT`, optional `ARENA_TOKEN` (MockUSDC if unset),
`ARENA_FEE_PER_PLAYER` (default 5000 = $0.005), `ARENA_MAX_FEE_PER_PLAYER` (default 1000000).
Output: `deployments/<chainId>.json` → `{ token, chessRules, channelHub }`.

## Encodings (shared with the TypeScript SDK)

- Square: `rank * 8 + file` (a1 = 0, h8 = 63). Board: 4 bits per square at offset `sq * 4`.
  Pieces `P N B R Q K = 1..6`, black adds 8.
- Meta: side (bits 0–7), castling `K=1 Q=2 k=4 q=8` (8–15), ep square or 255 (16–23),
  halfmove (24–39), ply (40–55), status `PLAYING DRAW_OFFERED WHITE_WON BLACK_WON DRAW = 0..4` (56–63).
- Move `uint32`: from (0–5), to (6–11), promotion 0 or 2–5 (12–14), kind (15–18):
  `NONE NORMAL NORMAL_OFFER_DRAW RESIGN ACCEPT_DRAW CLAIM_STALEMATE NEW_GAME = 0..6`.
- EIP-712 domain `AgentArena` / `1`; `prevHash` is the full EIP-712 digest of the previous state.

## External entry points and Circle CLI

Every state-changing entry point takes flat arguments or a single ABI-encoded `bytes` payload
(`deposit(bytes)`, `closeCooperative(bytes)`, `challenge(bytes)`, `respond(bytes)`, `timeout(bytes32)`,
`reclaim(bytes32)`, `claim(address)`), so it can be called with `circle wallet execute`. The Arc spike
(spec §10 step 0) must confirm `circle wallet execute` accepts a `bytes` argument.
```

```markdown
## 12. Implementation refinements (from Plan 1)

1. `IGameRules` also exposes `isCheckpoint(s)`, `isGameOver(s)`, `forfeitBalances(s, p)`; `ChessRules`
   additionally exposes `successor(prev, move, p)`, the canonical next state used for SDK parity.
```
